## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러나 우리 안에는 여전히 하나님의 뜻을 거스르려는 성향이 남아 있어서, 순종은 결심만으로 되지 않는다.
( ) 셋째 간구는 하나님의 뜻을 "알고", "순종하고", "복종하는" 것을 구하는 기도다.
( ) 그래서 순종은 내 노력의 결과물이 아니라, 하나님께서 은혜로 주셔야 하는 선물이다.
( ) 우리가 구할 뜻은 감추어진 뜻이 아니라 성경에 이미 나타난 뜻이며, 그 순종의 모범은 하늘의 천사들이다.
( ) 그러므로 이 기도는 매일의 작은 선택 속에서 조금씩 이루어져 가는 삶의 훈련이다.
