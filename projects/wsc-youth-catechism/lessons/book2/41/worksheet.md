## 2. 순서 맞춰보기 🔢
오늘 배운 첫째 간구의 논증 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

( ) 그 결과, 나의 작은 선택 하나하나가 하나님의 이름을 드러내는 자리가 될 수 있다.
( ) 하나님은 창조, 섭리, 말씀, 그리스도를 통해 자신을 알리신다.
( ) 하나님의 이름은 이미 완전히 거룩하며, 이 기도는 그 이름을 더 거룩하게 만들어달라는 것이 아니다.
( ) 이 간구는 나뿐 아니라 다른 사람들도 함께 하나님을 영화롭게 하기를 구한다.
( ) 다만 우리가 그 이름을 알아보고 마땅히 존중하며 영화롭게 하기를 구하는 기도이다.
