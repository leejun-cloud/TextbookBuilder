# 2권 제 31 과 활동지 — 말씀이 효력있게 되는 방법 (소요리문답 제 89 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 오늘의 문답을 완성해보세요.

문) 말씀은 어떻게 (　　　　　)에 효력 있게 되는가?
답) 하나님의 (　　　　　)께서는 말씀을 읽는 것, 특히 말씀을 (　　　　　)하는 것을,
(　　　　　)을 깨우쳐 (　　　　　)하게 하고 그들을 (　　　　　)으로 세워
(　　　　　)과 (　　　　　) 가운데 자라게 하며 (　　　　　)에 이르게 하는
효력 있는 방편으로 삼으신다.

## 2. 순서 맞춰보기 🔢
오늘 배운 "말씀이 효력을 내는 과정"을 순서대로 번호를 매겨보세요. (본문 Q2~Q5 참고)

(　) 말씀이 그 사람의 믿음을 세우고, 거룩함과 위로 가운데 계속 자라게 한다.
(　) 성령께서 굳은 마음을 부드럽게 하셔서 말씀을 받아들일 준비를 시키신다.
(　) 말씀이 읽히거나, 특히 설교로 전파된다.
(　) 부드러워진 마음에 말씀이 떨어져 죄인을 깨우치고 회개로 이끈다.

## 3. 나의 '말씀 받는 태도' 점검표 ✅
아래 항목을 솔직히 체크해보세요.

□ 나는 성경을 읽거나 설교를 듣기 전에, 성령께서 내 마음을 부드럽게 하시도록 기도한 적이 있다.
□ 나는 최근 한 달 안에 말씀을 듣다가 "이건 내 얘기다"라고 느낀 순간이 있었다.
□ 나는 말씀을 들은 뒤 회개나 실천으로 이어진 경험이 있다.
□ 나는 요즘 신앙생활에서 '거룩함'보다 '위로'가 더 필요하다고 느낀다. (또는 그 반대)
□ 나는 설교를 들을 때 종종 마음이 무감각하다고 느낀다.
