## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님의 이름과 관련된 죄(헛맹세, 습관적인 신앙 흉내 등)는 대부분 사람의 눈에 잘 드러나지 않는다.
( ) 그래서 사람의 법정은 이런 죄를 다룰 근거 자체가 없고, 이 죄를 지은 사람은 사람의 형벌을 피해간다.
( ) 그러나 하나님은 사람의 마음과 의도까지 다 헤아리시는 분이므로, 이 죄를 놓치지 않으신다.
( ) 이 땅에서 다 벌하거나 상 주지 못한 것들은 하나님의 의로운 심판의 날에 반드시 다뤄진다.
( ) 그러므로 제3계명에는 "사람은 못 다루더라도 내가 반드시 다룬다"는 하나님의 선언이 따로 붙어 있다.
