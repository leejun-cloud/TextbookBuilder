답) 타락한 사람은 자기 힘으로는 이 세상에서 하나님의 계명을 완전히 지킬 수 (　　　　), 오히려 (　　　　)과 (　　　　)과 (　　　　)로 날마다 그것을 어긴다.

## 2. 순서 맞춰보기 🔢
오늘 배운 핵심 논리의 흐름을 순서대로 번호(1~5)를 매겨보세요.

(　　) 그러므로 우리는 우리 힘으로 하나님 앞에 설 수 없고, 그리스도의 완전한 순종을 의지할 수밖에 없다.
(　　) 하나님의 율법은 생각과 말과 행위 전체를 다스리는 완전한 규범이다.
(　　) 타락한 사람은 자기 힘으로 이 계명을 완전히 지킬 수 없고 날마다 어긴다.
(　　) 그런데 모든 죄가 다 같은 무게는 아니며, 알고 지은 죄·반복된 죄 등은 더 무겁게 취급된다.
(　　) 그러므로 나는 죄를 뭉뚱그리지 않고, 개별적인 죄 하나하나를 구체적으로 살펴 회개해야 한다.
