## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하지만 마음이 하나님 두기를 싫어해서, 그 앎을 인정하지 않고 다른 것을 하나님 자리에 올려놓는다.
( ) 사람은 이미 마음속에 "하나님을 알 만한 것"을 갖고 있다.
( ) 그러므로 하나님이 정하신 방식대로 예배하고 그분께만 영광을 돌리는 것이 제1계명을 지키는 삶이다.
( ) 참된 예배는 내가 만든 방식이 아니라 하나님이 스스로 정하신 방식이어야 한다.
( ) 예배는 오직 성부, 성자, 성령께만, 오직 그리스도의 중보를 통해서만 드릴 수 있다.
