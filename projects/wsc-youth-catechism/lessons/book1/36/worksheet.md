# 활동지 36과 — 부활 때 받는 은택

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 신자가 부활할 때에 그리스도에게서 받는 은택은 무엇인가?
답: 신자는 부활할 때에 ______________ 가운데 다시 살아나고, 심판 날에 ______________ 인정받고 죄 없다 하심을 받으며, 영원토록 하나님을 온전히 ______________하는 완전한 복락을 누린다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 신자의 몸은 썩을 것에서 썩지 아니할 것으로, 욕된 것에서 영광스러운 것으로 성질이 변하여 다시 살아난다.
( ) 신자와 불신자 모두 몸으로 부활하지만, 의인의 부활과 악인의 부활은 그 결과가 다르다.
( ) 심판 날, 신자의 죄는 이미 용서받은 죄로서 드러나므로 정죄가 아니라 공개적인 인정이 된다.
( ) 몸이 완전히 회복되어야 사람 전체(영혼과 몸)가 온전히 구원받았다고 할 수 있다.
( ) 그리하여 신자는 영원토록 하나님의 얼굴을 보며 그를 온전히 즐거워하는 복락을 누린다.

## 3. 나의 '죽음과 부활 앞에서' 점검표 ✅

죽음, 노화, 질병에 대한 생각이 들 때 나는 주로 어떤 반응을 보이나요? (중복 가능)

- [ ] 애써 생각하지 않으려고 회피한다
- [ ] 막연한 두려움에 사로잡힌다
- [ ] 부활의 소망을 떠올리며 담대해진다
- [ ] 남의 일처럼 느껴져서 실감이 나지 않는다
- [ ] 오히려 지금 하루를 더 소중히 여기게 된다
- [ ] 기타: ___________

→ 위에서 표시한 반응 중, 오늘 배운 부활의 은택을 알았을 때 달라질 수 있는 부분이 있다면 무엇인가요?
