## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님의 섭리는 참새 한 마리, 머리털 하나까지 미치는 세세한 사역이다.
( ) '섭리'란 하나님이 미리 보시고 친히 감찰하시며 뜻하시고 행하시는 것이다.
( ) 그 섭리는 보전, 협력(운행), 통치라는 세 가지로 이루어진다.
( ) 이 모든 일은 하나님의 거룩하심과 지혜와 능력이 그대로 반영된 것이지 실수나 우연이 아니다.
( ) 그러므로 내 삶에 일어나는 일도 운명이나 우연이 아니라 하나님의 손 안에 있다.
