## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 하나님은 어떤 분이신가?
답: 하나님은 영이시니, 그의 존재와 지혜와 권능과 거룩하심과 공의와 선하심과 진실하심이 ______________하시고 영원하시며 ______________하시다.

문: 하나님 한 분 외에 또 다른 하나님이 계신가?
답: 오직 ______________뿐이시니, 살아 계시고 참되신 하나님이시다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 영이시라 형체가 없고 눈에 보이지 않으신다.
( ) 하나님은 시간과 공간에 제한받지 않는 무한하신 분이다.
( ) 하나님은 변함이 없으셔서 어제나 오늘이나 동일하시다.
( ) 그런데도 완전하신 하나님은 부족해서가 아니라 사랑으로 우리와 관계를 맺으신다.
( ) 그러므로 우리가 믿는 하나님은 여럿 중 하나가 아니라 유일하신 참 하나님이시다.
