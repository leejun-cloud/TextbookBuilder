# 활동지 — 1권 제 7 과 (소요리문답 제 8 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 제8문을 완성해 보세요.

문) 하나님께서는 자기의 (　　　　)을 어떻게 이루시는가?
답) 하나님께서는 자기의 작정을 (　　　　)와 (　　　　)의 사역으로 이루신다.

## 2. 순서 맞춰보기 🔢
오늘 배운 핵심 논리를 순서대로 번호(1~5)를 매겨보세요.

(　) 하나님은 지금도 만물을 보존하시고 운행하시며 다스리신다 — 이것이 섭리다.
(　) 하나님은 창세 전에 자기의 뜻대로 모든 것을 계획하셨다 — 이것이 작정이다.
(　) 참새 한 마리, 머리카락 한 올까지도 하나님의 섭리를 벗어나지 않는다.
(　) 그 계획은 태초에 무로부터 세계를 지으심으로 처음 실행되었다 — 이것이 창조다.
(　) 창조는 성부, 성자, 성령 하나님이 함께 이루신 사역이며, 하나님의 영광을 위한 것이다.

## 3. 창조와 섭리 구별하기 ✅
아래 문장이 '창조'에 해당하면 C, '섭리'에 해당하면 P를 괄호 안에 적어보세요.

1. 하나님이 엿새 동안 세상을 무로부터 지으셨다. (　)
2. 하나님이 지금도 공중의 새를 먹이시고 들의 풀을 입히신다. (　)
3. 하나님이 태초에 하늘과 땅을 창조하셨다. (　)
4. 하나님이 오늘도 우박을 녹여 곡식이 자라는 물이 되게 하신다. (　)
5. 성부, 성자, 성령이 함께 세계와 그 안의 만물을 만드셨다. (　)

짧은 서술형: 창조와 섭리, 이 둘 중 하나만 있고 다른 하나가 없다면 무엇이 문제일지 한두 문장으로 써보세요.
