# 활동지 — 2권 제 37 과 (소요리문답 제 96 문)

## 1. 오늘의 문답 외워보기 ✍️
아래 빈칸을 채워 소요리문답 96문을 완성해보세요.

문) 성찬이 무엇인가?
답) 성찬은 (        )와/과 (        )를/을 주고받는 성례이니, 이는 그리스도의 정하신 바를 따라 그의 (        )을/를 나타내는 것이요, 합당하게 참여하는 자들은 (        )의 방식이 아니라 (        )(으)로 그의 몸과 피에 참여하여 그로 말미암은 모든 유익을 받고 (        )과 (        ) 안에서 자라간다.

## 2. 순서 맞춰보기 🔢
오늘 배운 성찬에 관한 논증 흐름입니다. 아래 문장들을 올바른 순서대로 번호(1~5)를 매겨보세요.

(  ) 성찬은 예수님이 잡히시던 밤, 직접 떡과 잔을 주시며 "이를 행하여 나를 기념하라"고 정하신 성례다.
(  ) 그리스도의 몸과 피는 물질적으로 떡과 잔 안에 있는 것이 아니라, 믿음으로 받는 자에게 영적으로, 그러나 실제로 현존한다.
(  ) 세례가 그리스도와의 연합이 '시작'되는 표라면, 성찬은 그 연합이 '계속'되는 표다.
(  ) 합당하게 참여하는 자는 자기를 살피고 믿음으로 나아가며, 그로 말미암아 영적 양육과 은혜 안에서 계속 자라간다.
(  ) 성찬에 참여함으로써 그리스도께 속한 의가 나의 것으로 여겨지는 확신과 유익을 얻는다.

## 3. 나의 '성찬상 앞 태도' 점검표 ✅
아래 항목 중 나에게 해당하는 것에 체크해보세요.

□ 나는 성찬에 참여하기 전에 자기를 돌아보는 시간을 따로 가진 적이 있다.
□ 나는 성찬을 그냥 반복되는 형식적인 순서로 여긴 적이 있다.
□ 나는 성찬을 받을 때 그리스도의 죽으심이 '나를 위한' 것이라는 사실을 실감한 적이 있다.
□ 나는 세례와 성찬의 차이를 이번 시간 전까지 정확히 설명하지 못했다.
