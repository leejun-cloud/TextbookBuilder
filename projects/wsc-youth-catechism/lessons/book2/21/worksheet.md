## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그런데 이 계명은 법정 안에만 머물지 않고, 일상의 대화와 SNS 속 말에도 그대로 적용된다.

( ) 진실함을 지킨다는 것은 거짓말을 참는 소극적 자세를 넘어, 이웃의 명예를 있는 그대로 지키고 세우는 적극적인 태도다.
( ) 명예를 부당하게 깎아내리는 것도, 사실이 아닌데 부풀리는 것도 둘 다 진실을 왜곡하는 죄다.
( ) 그러므로 내가 하는 말 한마디가 사실인지 먼저 점검하는 습관이 이 계명을 지키는 첫걸음이다.
