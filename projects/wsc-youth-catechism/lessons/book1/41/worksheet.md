## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러나 사람은 하나님을 안다고 하면서도 마음에 하나님 두기를 싫어하고, 그 영광을 우상으로 바꾸어 버린다.
( ) 모든 것 위에 다스리시는 오직 한 분 하나님이 계시고, 그분을 마음을 다해 경외하고 사랑해야 한다.
( ) 그러므로 예배는 내가 편한 방식으로 지어내는 것이 아니라, 하나님 자신이 정하신 방식이어야 한다.
( ) 천사나 성인, 그 어떤 피조물도 예배의 대상이 될 수 없고, 오직 성부·성자·성령 하나님만이 예배를 받으신다.
( ) 타락 이후 우리는 오직 그리스도의 중보를 통해서만 하나님께 나아갈 수 있다.
