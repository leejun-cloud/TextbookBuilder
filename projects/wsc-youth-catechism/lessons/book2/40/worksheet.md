## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러나 우리가 스스로 그 관계를 만든 것이 아니라, 하나님이 아들을 통해 우리를 자녀 삼아 주셨기에 자격 없이도 나아갈 수 있다.
( ) 주기도문은 "하나님이시여"가 아니라 "아버지"라는 말로 시작하여, 우리가 어떤 관계 안에서 기도하는지를 먼저 알려준다.
( ) 그래서 우리는 하나님의 위대하심 앞에서 경외하면서도, 자녀 됨을 근거로 담대하게 나아갈 수 있다.
( ) 이 확신은 성령께서 우리 마음에 하나님의 자녀 됨을 확신시켜 주시기 때문에 가능한 것이다.
( ) 또한 "우리 아버지"라는 말은 내 기도가 나 혼자만의 부탁에 머물지 않고 다른 사람들을 위한 기도로 넓어져야 함을 가르친다.
