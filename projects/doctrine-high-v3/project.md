# 다음세대 교리교육 · 고등부 150과 (버전 3 · 축약 개정판)

전주서문교회 교육부. `doctrine-high-3stage`(버전 2)의 150과를 사용자 승인 1과 개정판
(3단계 축약본, 2026-08 승인)의 새 형식으로 전면 개정한 **새 교재**다.
버전 2 원고는 건드리지 않고, 이 프로젝트에 새 산출물을 만든다.

## 개요

| 항목 | 값 |
|---|---|
| 대상 | 고등부 1년차 (고 1) |
| 전체 분량 | 150과 (연 50과 × 3년) |
| 수업 시간 | 50분 · 학생이 쓰거나 말하는 시간 43분 |
| 진행 흐름 | 3단계 고정 — 1 나의 선 곳 보기 (8분) / 2 읽고 확인하여 이해하고 고백하기 (30분) / 3 말하고 결단하기 (12분) |
| 어투 | 단언형 `~이다` |
| 성경 번역 | 개역개정 |
| 산출물 | Word(DOCX). 학생용 지면(3면) + 교사 안내면(2면)을 한 파일에 담고, 배부 시 교사 안내면을 삭제한다 |
| 문서 디자인 | `doc-styles/doctrine-stage3.json` (1과 축약본 PDF 실측 프로필 그대로) |

## 버전 2와 달라진 것 (1과 개정판이 정의한 새 형식)

- 시간 배정 14·14·22(유형별 상이) → **8·30·12 고정.** 무게중심이 2단계로 옮겨졌다.
- 1단계는 본문 읽기가 아니라 **여는 질문에 먼저 답한 뒤** 핵심 교리 문장과 견주는 자리다.
- 따로 있던 보조본문과 확인을 **「찾기 ①②③」**(구절 낭독 → 내 말 한 줄 → 확인 대조)으로 붙였다.
- **KQCI는 3단계 마무리에서 2단계 이해 도구로 이동**했다. (K 키워드 2 · Q 질문 1 · C 핵심 문장 1 · I 깨달음 1)
- 탐구 질문·타임라인·쟁점 표·진단 표 등 1단계 유형 변주 장치는 지면에서 뺐다.
  **진행유형(서사형·논쟁형·적용형)은 여는 질문과 「이번 주 한 걸음」의 성격으로만 반영한다.**
- 평가 체크 + 교사 기록 표 → 학생 자기 점검 **「나의 확인」** 6항목. 교사 기록 표는 없다.
- 학생 지면 5~6면 → 3면, 필기 14줄 → 12줄, 학생 활동 37분 → 43분.

## 특수 지침 (모든 작업에서 최우선)

1. **전환이다. 재창작이 아니다.** 버전 2 원고의 확인 해설·성경 인용·예상 오답·교사 안내를
   재사용하고 새 구조에 맞게 줄인다. 새로 쓰는 것은 여는 질문·이번 주 한 걸음·나의 확인 등
   새 형식이 요구하는 자리뿐이다.
2. **spec.md의 원천 충실도는 그대로 유지한다.** 핵심 문장(2과부터 원문 그대로) · 주요 대지
   ①~④(교사면 「주요 대지 원문」에 그대로) · 중심 본문 · 암송구절 · ◎○ 표시.
3. **확인은 세 개, 찾기도 세 개.** 보조본문 ①②③이 찾기 ①②③이 되고 각각 확인 1·2·3과 짝이다.
   대지 ①→확인 1, ②→확인 2, ③+④→확인 3.
4. **귀납을 지킨다.** 여는 질문에 먼저 답한 다음 핵심 교리 문장을 읽는다. 찾기 안에서
   구절 → 내 말 한 줄 → 확인 순서를 바꾸지 않는다. 확인을 먼저 읽어 주지 않는다.
5. **성경 인용은 개역개정, 낫표 「」.** 버전 2에서 이미 검증된 인용을 글자 그대로 옮긴다.
   전환 중에 인용문을 고치지 않는다.
6. **학생용과 교사용을 분리한다.** 탐구 질문(교사 구두용) · 찾기별 도달 기준 · 예상 오답 ·
   교사가 말해 주는 것 · 어휘·연계·마스터 비고는 `teacher-notes.md`에만 둔다.
7. **▣유의 과**는 spec의 등급 지침을 교리 전달보다 앞세운다. (나) 등급은 「나의 확인」을
   자기 점검이 아닌 항목(암송·기록 여부)으로만 구성한다.
8. **읽기 주의는 교사면으로 옮긴다.** 1과 개정판이 학생 지면에서 뺐다(교사용 해설 「읽기 주의」).
   학생에게는 예상 오답 대응으로 교사가 구두 처리한다.

## 산출물 디자인과 변환

```bash
python3 scripts/lint_lesson.py projects/doctrine-high-v3/lessons/NNN/*.md
python3 scripts/qc_lesson.py projects/doctrine-high-v3/lessons --only N
python3 scripts/combine_lessons.py \
  --files projects/doctrine-high-v3/lessons/NNN/draft.md \
          projects/doctrine-high-v3/lessons/NNN/teacher-notes.md \
  -o projects/doctrine-high-v3/lessons/NNN/exports/<파일명>.docx \
  --style doctrine-stage3
```

분량 기준·필기 줄 기준은 `qc-config.json`이 지정한다(1과 기준본 실측).
