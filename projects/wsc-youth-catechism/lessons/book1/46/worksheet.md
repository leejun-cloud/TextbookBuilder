## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그 결과 하나님의 영광을 썩어질 사람과 짐승 모양의 우상으로 바꾼다.
( ) 사람은 만물을 통해 하나님을 알 만한 것을 분명히 볼 수 있다.
( ) 참되게 예배하는 자는 영과 진리로, 그리스도로 말미암아 예배해야 한다.
( ) 그런데도 사람은 하나님을 알되 영화롭게도 감사하지도 아니한다.
( ) 하나님의 진리를 거짓 것으로 바꾸어 피조물을 조물주보다 더 경배하고 섬긴다.
