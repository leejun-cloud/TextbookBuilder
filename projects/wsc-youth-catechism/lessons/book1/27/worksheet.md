# 활동지 — 1권 제 27 과 (소요리문답 제 29 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 29문을 완성해보세요.

문) 우리는 어떻게 그리스도께서 값 주고 사신 구속에 참여하는 자가 되는가?
답) 우리는 그리스도께서 값 주고 사신 (            )을 (            )께서 우리에게
(            ) 있게 (            )하심으로 그 구속에 참여하는 자가 된다.

## 2. 순서 맞춰보기 🔢
오늘 배운 논증의 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(   ) 성령께서 그리스도의 의를 나에게 효력 있게 적용하신다.
(   ) 그리스도께서 십자가에서 죽으심으로 죄값을 다 이루신다 (성취).
(   ) 나는 그리스도와 연합되어 구속에 참여하는 자가 된다.
(   ) 부활하고 승천하신 그리스도께서 약속하신 성령을 부어주신다.
(   ) 그리스도께서 부활하시고 승천하셔서 하나님 우편에 앉으신다.

## 3. 나의 '구속 체감' 점검표 ✅
아래 항목에 해당하면 체크해보세요.

□ 나는 그리스도의 십자가 사건을 그냥 '옛날에 있었던 일'로만 여긴 적이 있다.
□ 나는 최근 성경을 읽거나 기도할 때, 성령이 나에게 실제로 말씀하시거나 깨닫게 하신다고 느낀 적이 있다.
□ 나는 내 신앙을 "내가 열심히 믿어서 여기까지 왔다"고 생각하는 경향이 있다.
□ 나는 힘든 순간에 "성령께서 나를 붙들고 계신다"는 확신으로 버틴 적이 있다.

서술형: 최근 성령이 내 삶 속에서 구체적으로 일하고 계심을 느낀 순간이 있었다면, 그 순간을 한두 문장으로 적어보세요.
