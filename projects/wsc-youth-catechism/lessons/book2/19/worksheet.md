## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그런데 신앙고백서는 성도의 교제조차 각 사람의 소유권을 없애지 않는다고 분명히 밝힌다.
( ) 제8계명 "도둑질하지 말라"는 이웃 사랑을 구체화하는 계명들(제5-10계명) 중 소유권 문제를 다룬다.
( ) 그래서 74문은 "도둑질하지 말라"는 금지에서 더 나아가 "합법적으로 얻고 늘리는 것"이라는 적극적 책임까지 요구한다.
( ) 이때 "합법적으로"라는 표현은 결과가 아니라 방법의 정당성이 중요하다는 뜻이다.
( ) 그리고 이 재산은 나 자신뿐 아니라 다른 사람의 재산과 부를 위한 책임으로도 이어진다.
