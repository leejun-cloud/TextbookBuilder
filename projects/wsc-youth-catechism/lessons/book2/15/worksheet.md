## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그런데 사람은 하나님의 형상대로 지음 받은 존재이기에, 그 생명은 다른 피조물과 다르게 다뤄진다.
( ) 그래서 68문은 "살인하지 말라"는 금지에서 더 나아가 "정당한 노력을 다하여 생명을 보존하라"는 적극적 책임까지 요구한다.
( ) 제6계명 "살인하지 말라"는 이웃 사랑을 구체화하는 계명들(제5-10계명) 중 가장 먼저 등장한다.
( ) 예수님은 실제로 손을 대지 않아도, 마음속 미움과 분노까지 이 계명이 다루는 영역이라고 말씀하셨다.
( ) 자기 생명을 보존하는 것과 다른 사람의 생명을 보존하는 것, 이 둘 다 이 계명이 요구하는 책임이다.
