## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 이 세 가지 은혜의 순서는 시간의 순서가 아니라, 가르치기 위해 나누어 설명하는 신학적 순서('구원서정')이다.
( ) 하나님은 미리 정하신 자들을 부르시고, 부르신 자들을 의롭다 하시며, 의롭다 하신 자들을 영화롭게 하신다(롬 8:30).
( ) 부르심을 받은 사람은 하나님 앞에서 '의롭다'는 선언, 곧 칭의를 받는다.
( ) 동시에 하나님의 자녀로 삼아지는 양자됨을 받고, 그 순간부터 거룩해지는 성화가 시작된다.
( ) 이 세 은혜에는 양심의 평안, 성령 안의 기쁨, 견인의 힘 같은 부가적 은택이 함께 따라온다.
