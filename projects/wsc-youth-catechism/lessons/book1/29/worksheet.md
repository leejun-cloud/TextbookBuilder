## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 성령님이 우리 마음을 밝히 여셔서 그리스도를 알게 하신다.
( ) 성령님이 우리의 죄와 비참함을 먼저 깨닫게 하신다.
( ) 그 결과 우리는 복음 안에서 값없이 주시는 그리스도를 영접하고 믿게 된다.
( ) 성령님이 우리의 굳은 의지를 새롭게 하셔서 선한 것을 향하게 하신다.
( ) 이 모든 과정은 우리의 결심이 아니라 하나님의 효과적인 부르심으로 시작된다.
