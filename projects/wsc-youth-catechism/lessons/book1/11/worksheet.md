## 2. 순서 맞춰보기 🔢

( ) 하나님이 스스로 낮추셔서 사람과 '언약'의 방식으로 관계를 맺기를 기뻐하셨다.
( ) 그 언약의 조건은 "완전하고 인격적인 순종"이었고, 순종하면 생명을 주시겠다고 약속하셨다.
( ) 그 조건은 선악을 알게 하는 나무의 열매를 먹지 않는, 감당하기 어렵지 않은 것이었다.
( ) 그런데도 아담은 이 조건을 저버렸고, 이는 반역이었으며 죽음의 형벌이 임했다.
( ) 아담이 언약의 머리였기에 그의 불순종은 모든 후손에게 전가되었다.
