답: 제1계명에서 "내 앞에서"라는 말씀은, ______________ 보시는 하나님께서 다른 신을 두는 죄를 아시고 ______________ 싫어하시니, 그것으로 그분을 ______________ 하지 말라는 것을 가르친다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 제1계명 끝에 "내 앞에서"라는 말이 붙어, 이 계명이 지켜지고 어겨지는 자리가 바로 하나님의 얼굴 앞임을 알려준다.
( ) 하나님의 눈은 온 땅을 두루 감찰하시며, 그 지식은 시공에 갇히지 않고 무한하다.
( ) 예배는 오직 하나님 한 분께만 드려야 하므로, 다른 신을 두는 것은 그 관계의 핵심을 무너뜨리는 죄다.
( ) 하나님은 이 죄를 심히 싫어하시며, 그것으로 자신을 노엽게 하지 말라고 경고하신다.
( ) 이 경고는 우리를 겁주려는 것이 아니라, 하나님과 우리의 관계를 지키시려는 사랑의 표현이다.

## 3. 나의 '하나님 앞에서' 점검표 ✅

아무도 보지 않는 것 같은 순간, 나는 주로 어떤 모습인가요? (중복 가능)

- [ ] 사람들 앞에서와 크게 다르지 않게 행동한다
- [ ] 긴장이 풀어져서 평소와 다른 모습이 된다
- [ ] 마음속으로 은근히 다른 무언가(성공, 인정, 돈)를 더 의지하게 된다
- [ ] "누가 알겠어"라는 생각이 스치듯 든다
- [ ] 오히려 하나님이 보고 계신다는 게 떠올라 마음이 다잡아진다
- [ ] 기타: ___________

→ 위에서 표시한 모습 중, 오늘 배운 "내 앞에서"라는 말씀을 알았을 때 달라질 수 있는 부분이 있다면 무엇인가요?
