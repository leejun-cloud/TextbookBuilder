## 2. 순서 맞춰보기 🔢
오늘 배운 네 가지 이유의 논증 흐름을 순서대로 번호를 매겨보세요.

(　) 하나님이 창세기 2장 2절에서 친히 쉬시며 안식의 본을 보이신다.
(　) 이렛날을 특별하게 대하는 것은 우리의 임의가 아니라, 하나님이 창조 때부터 그날을 자기 소유로 구별하신 질서를 따르는 일이다.
(　) 하나님은 먼저 엿새 동안 우리의 생업을 위해 힘써 일할 시간을 허락하신다.
(　) 하나님은 일곱째 날을 복되게 하시고 거룩하게 하셔서, 그날에만 고유한 복과 거룩함을 더해주신다.
(　) 신약에서 그리스도의 부활을 통해 이 안식이 완성되어 오늘 우리가 지키는 주일이 된다.

## 3. 네 가지 이유 점검표 ✅
아래 각 이유가 나에게 얼마나 실감 나는지 체크해보세요.

□ 하나님이 엿새를 허락하신 것이 감사하게 느껴진다
□ 이렛날이 하나님의 것이라는 사실을 평소에 의식하고 산다
□ 하나님이 친히 쉬셨다는 게 나의 쉼에 대한 죄책감을 덜어준다
□ 주일에 특별한 복이 있다는 것을 실제로 경험한 적이 있다
