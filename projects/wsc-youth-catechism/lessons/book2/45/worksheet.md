## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 죄를 자백하는 자에게 그리스도를 위하여 우리의 모든 죄를 값없이 용서해 주신다.
( ) 이미 하나님의 자녀가 된 사람도 자기 죄로 아버지와의 친밀함을 잃을 수 있어, 계속해서 고백하고 용서를 구해야 한다.
( ) 그런데 내가 남을 진심으로 용서할 수 있게 된 것 자체가, 내 안에 하나님의 용서하시는 은혜가 이미 들어와 있다는 증거다.
( ) 그러므로 다섯째 간구는 "저를 용서해 주세요"와 "제가 아직 용서 못한 사람도 고쳐 주세요"를 함께 하나님께 가져가는 기도다.
( ) 그래서 우리는 남을 용서한 은혜를 근거로, 담대하게 하나님께 나의 용서를 구할 수 있다.
