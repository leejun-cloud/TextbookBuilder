# 활동지 — 2권 제 36 과 (소요리문답 제 95 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 95문을 완성해보세요.

문) 세례는 누구에게 베풀어야 하는가?
답) 세례는 (        ) 밖에 있어 그리스도를 믿는다고 (        )하지 않고 그분께 (        )하지 않는 자에게는 베풀지 않으나, (        ) 회원의 (        )들에게는 세례를 베푼다.

## 2. 순서 맞춰보기 🔢
오늘 배운 "유아세례가 정당한 이유"의 논증 흐름입니다. 올바른 순서대로 번호(1~5)를 매겨보세요.

(   ) 사도행전에는 루디아, 빌립보 간수, 회당장 그리스보처럼 가정 전체가 함께 세례를 받는 장면이 반복해서 나온다.
(   ) 하나님은 아브라함에게 "너와 네 후손"에게 영원한 언약을 세우겠다고 말씀하셨다(창 17:7).
(   ) 그 언약의 표징이었던 할례는 유아 때 이미 받는 것이었다(창 17:9-14).
(   ) 신약의 세례는 이 할례의 자리를 이어받은 "그리스도의 할례"라 불린다(골 2:11-12).
(   ) 그러므로 믿는 부모의 자녀는 스스로 믿음을 고백하기 전에도 언약 백성의 자녀로서 세례를 받는다.

## 3. 나의 세례를 돌아보는 점검표 ✅
아래 항목에 해당하는 것에 체크해보세요.
□ 나는 유아 때 부모님(혹은 조부모님)의 신앙을 따라 세례를 받았다.
□ 나는 성인이 되어 스스로 신앙을 고백하고 세례를 받았다.
□ 나는 아직 세례를 받지 않았다.
□ 나는 내가 세례를 받은 날짜와 그 의미를 정확히 알고 있다.

짧은 서술형 질문: 위 항목 중 내가 체크한 상황이, 오늘 배운 "믿는 자의 고백"과 "언약 자녀"라는 두 갈래 중 어디에 더 가까운지, 그리고 그 사실이 지금 나의 신앙생활에 어떤 의미로 다가오는지 3~4문장으로 적어보세요.



## 4. 한 문장으로 설명하기 🗣️
세례를 받아본 적 없는 비신자 친구가 "너희 교회는 왜 아기한테도 세례를 준다는 거야? 애가 무슨 믿음이 있다고?"라고 묻는다면, 오늘 배운 "언약"이라는 개념을 써서 어떻게 설명해줄지 한두 문장으로 적어보세요.
