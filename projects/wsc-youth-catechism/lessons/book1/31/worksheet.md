## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 우리는 이 전가된 의를 오직 믿음으로 받아들인다 — 믿음은 공로가 아니라, 이미 이루어진 것을 받아들이는 도구일 뿐이다.
( ) 하나님은 값없이 은혜를 베푸사 우리의 모든 죄를 사하시고, 우리를 자기 앞에서 의롭다고 받아들이신다.
( ) 우리 속에 의를 주입해서 실제로 착해지게 하시는 방식이 아니라, 그리스도께서 이미 이루신 의를 우리 것으로 전가하시는 방식이다.
( ) 값없이 주어진 은혜이지만, 값이 아예 없었던 것은 아니다 — 그리스도께서 순종과 죽음으로 그 값을 대신 온전히 치르셨다.
( ) 하나님이 영원 전부터 이 은혜를 작정하셨어도, 성령이 실제로 나를 그리스도와 연합시키시는 그 순간에야 비로소 칭의는 나의 것이 된다.

## 3. 나의 '칭의 확신' 점검표 ✅

요즘 나의 상태에 해당하는 것에 표시해보세요. (중복 가능)

- [ ] 나는 하나님 앞에서 "이미 의롭다 하심을 받았다"는 확신이 있다
- [ ] 나는 여전히 내 행위로 나 자신을 증명해야 한다고 느낀다
- [ ] 나는 실수하거나 죄를 지을 때마다 하나님과의 관계가 흔들린다고 느낀다
- [ ] 잘 모르겠다 / 이런 생각을 깊이 해본 적이 없다
