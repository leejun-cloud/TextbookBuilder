## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 부모라는 자리는 사람이 스스로 만든 것이 아니라 하나님이 세우신 질서다.
( ) 그래서 부모를 공경하지 않는 것은 단지 집안 문제가 아니라, 그 질서를 세우신 하나님을 향한 문제이기도 하다.
( ) 십계명은 하나님을 향한 첫 네 계명과 이웃을 향한 나머지 여섯 계명으로 나뉘는데, 그중 부모 공경이 이웃 사랑의 첫 자리를 차지한다.
( ) 다만 참된 공경은 두려움 때문이 아니라, 그 질서를 마음으로 인정하는 양심에서 나온다.
( ) 그러므로 부모를 공경하는 법을 배운 사람은 삶의 다른 권위 앞에서도 쉽게 무너지지 않는다.
