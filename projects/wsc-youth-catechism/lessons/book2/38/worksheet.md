문) 성찬에 합당하게 참여하기 위해 요구되는 것은 무엇인가?
답) 성찬에 합당하게 참여하려는 사람은 주님의 몸을 (        )하는 지식과, 자신을 (        )는 것과, 그리스도를 먹는 (        )과, (        )와, (        )과, 새로운 (        )으로 자신을 살펴야 하니, 그렇지 않으면 합당하지 않게 참여하여 자기에게 (        )을 먹고 마시는 것이 된다.

## 2. 순서 맞춰보기 🔢
아래 문장들은 오늘 본문(Q1~Q6)에서 다룬 핵심 논리의 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(  ) 성찬은 아무 준비 없이 습관적으로 받으면 오히려 심판을 자초할 수 있다.
(  ) 성찬에 나아가기 전, 나의 신앙과 삶의 상태를 정직하게 살펴야 한다.
(  ) 떡과 잔이 그리스도의 몸과 피를 나타내는 표징임을 아는 지식이 필요하다.
(  ) 물리적으로 떡과 잔을 삼키는 것 자체가 아니라, 믿음으로 그리스도를 붙잡아야 은혜가 임한다.
(  ) 회개, 사랑, 새로운 순종은 성찬 이후의 부록이 아니라 나아가기 위한 조건이다.
