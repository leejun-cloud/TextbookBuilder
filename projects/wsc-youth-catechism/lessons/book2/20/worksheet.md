답) 제8계명이 금하는 것은 자기 자신이나 이웃의 (        )과 (        )에 (        )하게 손해를 끼치거나 손해 끼칠 만한 (        ) 일이다.

## 2. 순서 맞춰보기 🔢
오늘 "말씀 속으로 한 걸음"에서 다룬 논리를 순서대로 번호를 매겨보세요.

(  ) 아나니아와 삽비라처럼, 재산과 관련해서 속이려는 마음도 이 계명을 어기는 일이다.
(  ) "부당하게"라는 말은 정당한 경제활동과 이웃에게 손해를 끼치는 방식을 구별해준다.
(  ) 자기 재산도 하나님이 맡기신 것이므로, 낭비하고 탕진하는 것도 이 계명이 금하는 자리에 있다.
(  ) 실제 손해가 없어도 손해를 향한 태도와 시도 자체가 이미 문제다.
(  ) 결국 도둑질과 착취는 마음속 탐심이 기회를 만나 터져 나온 결과다.
