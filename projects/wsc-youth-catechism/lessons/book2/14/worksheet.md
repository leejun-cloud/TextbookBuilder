## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 에베소서는 제5계명을 "약속이 있는 첫 계명"이라 부르며, 지키는 자에게 장수와 형통을 약속한다.
( ) 그런데 부모를 공경하며 산 사람 중에도 일찍 세상을 떠나거나 어려움을 겪는 경우가 있다.
( ) 그래서 소요리문답은 이 약속에 "하나님의 영광과 그들 자신의 유익에 도움이 되는 한"이라는 조건을 붙인다.
( ) 요셉의 삶처럼, 겉으로 장수·형통처럼 보이지 않는 시간에도 하나님은 합력하여 선을 이루신다(롬 8:28).
( ) 그러므로 장수와 형통을 목표로 삼기보다, 하나님을 영화롭게 하는 삶 가운데 그 복이 하나님의 방식으로 따라온다는 것을 신뢰해야 한다.

## 3. 나의 '부모 공경' 점검표 ✅

내가 평소 부모님을 대하는 마음과 태도는 어떤가요? (중복 가능)

- [ ] 부모님을 공경하는 것을 "복 받기 위한 조건"처럼 생각한 적이 있다
- [ ] 원하는 만큼 일이 잘 안 풀릴 때, 내 노력이 헛되다고 느낀 적이 있다
- [ ] 부모님께 마음은 있지만 구체적인 행동으로 잘 표현하지 못한다
- [ ] "잘되고 오래 사는 것"이 내 삶에서 은근히 가장 중요한 목표가 되어 있다
- [ ] 힘든 시간을 지나면서도 하나님이 선을 이루고 계신다고 믿어본 적이 있다
- [ ] 기타: ___________
