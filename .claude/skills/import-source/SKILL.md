`/import-source`는 외부 원천 자료(예: 소요리문답 해설집)를 프로젝트의 `sources/` 폴더에 마크다운으로 정리해 넣는 작업이다. 다음 순서를 정확히 따른다.

## 1. 정보 확인

사용자가 아래 두 가지를 미리 주지 않았다면 먼저 물어본다.

- 원본 파일 경로 (HWP/HWPX/DOCX/PDF/TXT/MD 중 하나)
- 어느 프로젝트(`projects/<project-id>`)에 속하는 자료인지 — 프로젝트가 하나뿐이면 확인만 하고 넘어간다.

## 2. 파일 형식별 변환

원본 확장자에 따라 다음 방법으로 마크다운으로 변환한다.

- `.hwp` / `.hwpx` → `python3 scripts/hwp_convert.py <원본경로> -o <임시경로>.md`
  - `.hwp`(구 바이너리) 파일은 내부적으로 `hwp5txt`(pyhwp)를 필요로 한다. 스크립트가 설치 안내와 함께 오류를 내면, 사용자에게 `pip3 install pyhwp` 안내를 그대로 전달하거나 한컴오피스/한글Viewer에서 `.hwpx`나 `.txt`로 다시 저장해달라고 요청한다.
- `.docx` → `pandoc -t markdown_strict <원본경로> -o <임시경로>.md`
- `.pdf` → `pdftotext <원본경로> <임시경로>.txt` 실행 후, 페이지 구분자·머리글/바닥글 반복 등 불필요한 잡음을 정리해 마크다운으로 다듬는다.
- `.md` / `.txt` → 그대로 복사한다(내용 변경 없음).

변환 도구(`pandoc`, `pdftotext`)가 시스템에 없으면 설치 방법(`brew install pandoc`, `brew install poppler`)을 안내하고 중단한다.

## 3. 저장 위치 결정

변환된 마크다운은 `projects/<project-id>/sources/`에 저장한다.

- 분량이 많은 자료(여러 문항/장을 아우르는 해설집 등)는 장별로 나누는 것이 이후 집필 작업에 유리하다. `.hwp`/`.hwpx`의 경우 변환 시 바로 아래처럼 분할할 수 있다.
  ```
  python3 scripts/hwp_convert.py <원본경로> --split-by-heading projects/<project-id>/sources/<slug>/
  ```
  이때 `<slug>`는 자료 이름을 영문/숫자/하이픈으로 슬러그화한 것(예: `haeseol`)이다. 분할 여부는 자료 성격을 보고 판단하되, 애매하면 사용자에게 물어본다.
- 분량이 적으면 단일 파일로 `projects/<project-id>/sources/<slug>.md`에 저장한다.

## 4. `자료목록.md` 생성/갱신

`projects/<project-id>/sources/자료목록.md`를 읽고(없으면 새로 만들고), 이번에 추가한 자료에 대해 다음 항목을 표 또는 목록으로 기록한다.

- **파일명**: 저장된 경로 (분할된 경우 폴더와 파일 패턴, 예: `sources/haeseol/01_*.md`)
- **원본 형식**: 변환 전 확장자
- **역할**: 사용자에게 반드시 물어서 다음 중 하나로 명시한다.
  - 주 원천 자료 (본문 집필의 근거가 되는 자료)
  - 보조 참고 자료
  - 스타일 참조 자료 (문체·구성 참고용)
- **사용 지침**: 역할에 맞는 지침을 적는다. 예: "본문은 반드시 이 자료에 근거하며 임의로 왜곡하지 않는다", "문체 참고용으로만 사용하고 내용을 그대로 인용하지 않는다".
- **분할 여부와 범위**: 분할했다면 어느 파일이 어느 문답/장을 담고 있는지 안내(예: "01_*.md = 제1~5문", "02_*.md = 제6~10문"). 분할하지 않았다면 "분할 없음"으로 표기.

기존 `자료목록.md` 내용은 지우지 말고 새 항목을 추가하는 방식으로 갱신한다.

## 5. 결과 보고

사용자에게 다음을 요약해서 보고한다.

- 변환 결과 요약 (문단 수, 표 수, 추출 글자 수 — `hwp_convert.py` 출력 그대로 활용)
- 생성/갱신된 파일 목록 (전체 경로)
- 각 과(레슨)의 `input.md`에서 이 자료를 참조할 때 `sources/<slug>/NN_*.md` 형태의 원천 범위를 지정할 수 있다는 점을 안내한다.
