# 활동지 40과 — 십계명의 서문과 의미

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 십계명의 머리말은 무엇인가?
답: 십계명의 머리말은 "나는 너를 애굽 땅 ______________ 되었던 집에서 인도하여 낸 너의 하나님 ______________로라" 하신 것이다.

문: 십계명의 머리말이 우리에게 가르치는 것은 무엇인가?
답: 십계명의 머리말은 하나님께서 여호와시요 우리 하나님이시며 ______________이심을 가르치니, 그러므로 우리는 그의 ______________을 지켜야 한다는 것을 가르친다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 이스라엘 백성을 애굽의 종살이에서 먼저 건져 내셨다.
( ) 그다음에야 시내 산에서 십계명을 주셨다.
( ) 머리말은 하나님이 여호와시요 우리 하나님이시며 구속자이심을 밝힌다.
( ) 그러므로 계명은 구원을 얻기 위한 조건이 아니라 이미 받은 구원에 대한 응답이다.
( ) 우리는 두려움이 아니라 감사함으로 그의 모든 계명을 지켜야 한다.

## 3. 나의 '순종의 동기' 점검표 ✅

지난 한 주, 신앙의 규칙(예배, 경건생활, 말과 행동 등)을 지킬 때 내 마음에 가까웠던 것에 표시해보세요. (중복 가능)

- [ ] 안 지키면 벌 받을 것 같아서
- [ ] 사람들 눈이 있어서
- [ ] 이미 받은 은혜가 고마워서
- [ ] 습관이라 별생각 없이
- [ ] 지키고 싶었지만 지키지 못했다
- [ ] 기타: ___________

→ 위에서 표시한 것 중, 오늘 배운 "머리말"의 순서(은혜가 먼저, 순종은 그다음)와 가장 먼 항목은 무엇인가요? 왜 그런 것 같나요?
