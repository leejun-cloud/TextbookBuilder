## 2. 순서 맞춰보기 🔢
아래는 오늘 배운 인간 창조의 흐름입니다. 뒤섞인 순서를 번호(1~5)로 다시 매겨보세요.

(　) 하나님이 사람에게 생육하고 번성하며 땅을 다스리는 권세를 맡기셨다.
(　) 하나님이 다른 모든 피조물을 먼저 만드신 후 마지막으로 사람을 창조하셨다.
(　) 흙으로 사람의 몸을 빚으시고 생기를 불어넣어 생령이 되게 하셨다.
(　) 사람을 남자와 여자로 창조하시고, 둘 다 동등하게 하나님의 형상을 지니게 하셨다.
(　) 사람에게 하나님을 아는 참된 지식과 의와 거룩함을 갖추어 지으셨다.
