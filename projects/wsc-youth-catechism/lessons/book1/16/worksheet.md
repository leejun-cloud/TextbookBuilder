# 활동지 16과 — 타락한 상태의 죄악됨

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 사람이 타락한 상태에서의 죄악됨은 무엇인가?
답: 사람이 타락한 상태에서의 죄악됨은 아담의 첫 범죄의 ______________과, 근원적 ______________의 결여와, 그의 온 본성의 ______________(이를 ______________라 한다)와, 그로부터 나오는 모든 ______________들에 있다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 죄악됨 네 요소의 순서대로 번호를 매겨보세요. ( ) 안에 1~4 숫자를 쓰세요.

( ) 그 결과 태어날 때부터 이미 하나님의 뜻에 순종할 능력, 곧 근원적 의를 잃어버린 상태다.
( ) 아담이 온 인류의 대표로서 범죄했기에, 그 죄책이 언약의 원리에 따라 나에게도 돌려진다.
( ) 이 오염은 영혼과 몸 전체에 미쳐 머리에서 발끝까지 성한 곳이 없는 본성의 부패, 곧 원죄가 된다.
( ) 이렇게 부패한 본성에서 거짓말, 분노, 미움 같은 실제적 범죄들이 흘러나온다.

## 3. 나의 '죄의 뿌리' 점검표 ✅

지난 한 주, 내가 반복해서 지었던 죄를 떠올리며 표시해보세요. (중복 가능)

- [ ] 짜증 / 분노
- [ ] 험담 / 비교하는 마음
- [ ] 게으름 / 회피
- [ ] 정욕적인 생각이나 행동
