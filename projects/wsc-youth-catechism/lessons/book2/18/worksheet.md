## 2. 순서 맞춰보기 🔢
오늘 "말씀 속으로 한 걸음"에서 다룬 순결의 논리를 순서대로 번호를 매겨보세요.

(  ) 이혼도 정당한 사유 없이는 그 자체로 제7계명을 거스르는 일이다.
(  ) 마음속 생각과 시선(눈)이 이미 순결을 해칠 수 있다.
(  ) 순결하지 못한 말(혀)은 새로운 불결한 생각을 만들어낸다.
(  ) 결혼 밖의 성적 결합뿐 아니라, 결혼 안에서도 절제 없는 방종은 금지된다.
(  ) 순결은 몸의 행동만이 아니라 생각·말·행동 전체의 문제다.
