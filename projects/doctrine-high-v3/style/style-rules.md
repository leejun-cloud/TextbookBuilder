# 스타일 규칙 — 고등부 교리공과 버전 3 (축약 개정판)

기준본: `lessons/001/draft.md` + `lessons/001/teacher-notes.md` (사용자 승인 1과 3단계 축약본).
**이 문서와 001의 두 md 파일이 형식의 유일한 기준이다.** 001을 열어 형태를 눈으로 확인하고 쓴다.

이 프로젝트는 **전환**이다. 버전 2(`../doctrine-high-3stage/lessons/NNN/`)의 검증된 원고에서
내용을 가져와 새 구조에 담는다. 새로 쓰는 것은 새 형식이 요구하는 자리(여는 질문 · 찾기 제목 ·
이번 주 한 걸음 · 돌아가기 빈칸 문장)뿐이다.

## 0. 절대 규칙

1. **원천 충실도.** `spec.md`의 과 번호 · 주제 · 중심 본문 · 암송구절 · ◎○ 표시는 그대로.
   **핵심 문장은 spec 원문 그대로** 핵심 교리 문장 박스에 넣는다(굵게). 주요 대지 ①~④는
   교사면 「주요 대지 원문」에 문장 그대로 옮긴다.
2. **성경 인용은 개역개정, 낫표 「」.** 버전 2 원고의 인용은 이미 교차 검증되었다 —
   **글자 그대로 복사한다. 전환 중에 기억으로 다시 쓰지 않는다.** 새 인용을 추가하지 않는다.
   버전 2에 `<!-- 확인요청: … -->`이 남아 있으면 그대로 가져와 남긴다.
   **낫표는 성경과 WSC 인용에만 쓴다.** 세상의 주장·대지 조각·확인 문장 조각·용어를 인용할 때는
   큰따옴표 `"…"`를 쓴다 (verse_carryover가 낫표 안을 성경 인용으로 간주한다).
3. **확인은 세 개, 찾기도 세 개.** 보조본문 ①②③ = 찾기 ①②③, 각각 확인 1·2·3과 짝.
   대지 ①→확인 1, ②→확인 2, ③+④→확인 3 (대지 3개면 ③→확인 3).
4. **귀납을 지킨다.** 여는 질문에 먼저 답한 뒤 핵심 교리 문장을 읽는 순서를 바꾸지 않는다.
   찾기 안에서 구절 → 내 말 한 줄 → 확인 순서를 바꾸지 않는다. 1·2단계 지면에 답을 미리
   적지 않는다. 낱말 뜻은 예외로 1면에서 알려 준다.
5. **중심본문 경계를 넘지 않는다.** spec 마스터 비고의 본문 경계를 지킨다.
6. **학생용과 교사용을 분리한다.** 탐구 질문 · 읽기 주의 · 도달 기준 · 예상 오답 · 어휘 ·
   연계 · 마스터 비고는 `teacher-notes.md`에만 둔다. **읽기 주의는 학생 지면에 넣지 않는다**
   (버전 2와 다른 점 — 1과 승인본이 뺐다).
7. **어투는 단언형 `~이다`.** 학생 지시는 1과 승인본을 따라 `~한다`·`~적는다`형 서술
   (예: "아래 질문에 먼저 답한다", "한 줄로 쓴다"). `~하라`체는 쓰지 않는다(버전 2와 다른 점).
   경어체는 기도문과 WSC 인용에서만.
8. **신앙고백은 WSC만 학생 지면에.** 질문+답을 `[[BOX:WSC 제N문   <질문>]]` 형태로.
   하이델베르크·기독교강요는 교사면 「교사용 해설」로만.
9. **진행유형(서사형·논쟁형·적용형)은 지면 구조를 바꾸지 않는다.** 세 단계 이름·시간은 150과
   모두 같다. 유형은 **여는 질문과 「이번 주 한 걸음」의 성격**으로만 반영한다(§2 참조).
   타임라인·쟁점 표·진단 표·평가 체크·교사 기록 표는 만들지 않는다.
10. **▣유의 과**는 spec 등급 지침을 교리 전달보다 앞세운다. (나) 등급은 「나의 확인」에서
    자기 상태를 점검하는 항목을 빼고 수행 여부(암송·기록)만 남기며, 묘사 수위를 낮춘다.

## 2. `draft.md` 지면 순서 (고정)

```
# COVER                      ← 작은제목 "다음세대 교리교육 · 고등부 N년차 (고 1)  |  수업 50분  |  전주서문교회 교육부"
                               큰제목 "N 과   <주제>" · 부제 "나의 선 곳 보기 · 읽고 확인하여 이해하고 고백하기 · 말하고 결단하기"
# 핵심 교리 문장              ← [[BOX:]] 안에 **spec 핵심 문장 원문**(굵게)만. 보충 문장 없음
| 정보표 |                    ← [[TABLE:label]] 단원/중심 본문/보조본문/암송구절 4행.
                               보조본문 행 끝에 "(2단계 찾기 ①②③에서 확인과 함께 읽는다)"
# 먼저 알아 둘 말 N 개        ← **낱말** 뜻. 3~4개. 찾기·확인이 실제로 쓰는 말만. spec 어휘에서 고른다
# 1. 나의 선 곳 보기          8 분 (내가 쓰고 말하는 시간 7 분)
# 2. 읽고 확인하여 이해하고 고백하기          30 분 (내가 쓰고 말하는 시간 25 분)
# 이해 정리 — KQCI          9 분
# 함께 나누기          3 분
# 교회의 고백과 잇기          3 분
# 3. 말하고 결단하기          12 분 (내가 쓰고 말하는 시간 10 분)
# 나의 확인
# FOOTER                     ← "<주제> N 과  |  고등부"
```

배너는 `# 1.` `# 2.` `# 3.` 세 개만. 그 사이 소제목은 `# 제목`(번호 없이).
**`## `를 절대 쓰지 않는다** — 렌더러가 그 뒤 전부를 문답 쌍으로 잘못 읽는다.

### 1단계 안의 순서

1. 도입 한 줄: `오늘 배울 것을 한 문장으로 들은 뒤(선생님이 1분 안에 말해 준다), 아래 질문에 먼저 답한다.`
2. `**① 여는 질문 — 답을 찾기 전에 먼저 답한다     4 분**`
   - `[[BOX:]]` 안에 **여는 질문**(굵게) + 질문을 정의해 주는 한 줄.
   - 안내 한 줄: `아래에서 골라도 되고, 없으면 내가 직접 써도 된다. 무엇을 골라도 괜찮다. 점수를 매기지 않는다.`
   - `□` 선택지 3개(각각 `— 짧은 부연`) + `□ 내가 쓰는 것 __________________________`
   - `왜 그것이라고 생각하는가? 한 문장으로 옆 사람에게 말한다.`
3. `**② 핵심 교리 문장을 읽고, 나의 생각과 의문     3 분**` — 1과 문구 그대로 +
   `가장 걸리는 말 하나 (예: <이 과 핵심 문장의 어려운 말 3~4개>)  ______________________` +
   의문 쓰기 안내 + `[[WRITING_BOX:1]]`

**여는 질문의 유형별 성격** — 버전 2의 3단계 ① 세계관 이슈(spec 「세계관 이슈와 토의 질문」)를
1단계로 앞당겨 만든다. 선택지 3개는 모두 고 1의 실제 자리여야 하고 하나를 정답으로 두지 않는다.

| 유형 | 여는 질문의 꼴 |
|---|---|
| 서사형 | 나의 실제 자리를 스스로 진단한다 (예: "나를 지금 실제로 다스리고 있는 것은 무엇인가?") |
| 논쟁형 | 세상이 하는 주장 하나를 놓고, 배우기 전의 내 생각을 먼저 적는다 (예: "…라는 말을 들으면 나는 지금 어느 쪽에 가까운가?") |
| 적용형 | 나의 지난 한 주를 사실 하나로 진단한다 (예: "지난주에 …했던 순간은 언제였나?") |

### 2단계 안의 순서

1. `먼저 중심본문을 두 번 읽는다. 지금은 설명을 붙이지 않는다. 눈에 걸리는 말에 밑줄만 그어 둔다.`
2. `[[BOX:중심본문 · <책 장:절>]]` 인용 + 어려운 낱말 한 개 풀이(`낱말 — 뜻.` 형식, 없으면 생략)
3. 찾기 안내 문단(1과 문구 그대로): `아래 「찾기」 셋은 보조본문 하나와 확인 하나로 되어 있다. …`
4. 찾기 ①②③ — 각각 이 5요소를 이 순서로:
   - `**찾기 ① — <내용 질문>**` (그 확인이 답이 되는 질문. 예: "왕은 어디까지 다스리시는가")
   - `[[BOX:<책 장:절>]]` 보조본문 인용 (버전 2에서 글자 그대로)
   - `내 말로 한 줄` + `[[WRITING_BOX:1]]`
   - `[[BOX:확인 N — <확인 문장>]]` 안에 해설 1문단 2~4문장 (버전 2 확인 해설 2문단을 압축.
     본문의 말을 짚어 주는 문장을 남기고 핵심 문장 반복은 버린다)
   - 손들기 줄(고정): `내가 쓴 한 줄에 이 내용이 들어 있었나?   ○ 있었다   △ 비슷하다   × 없었다   (반 전체가 손을 들어 함께 표시한다)`
5. `# 이해 정리 — KQCI          9 분` — 안내 문단(1과 그대로) + **K 키워드 2개** / **Q 나의 질문 1개** /
   **C 핵심 문장 1개** / **I 이해와 깨달음 1개** 각 설명과 `[[WRITING_BOX:1]]` (설명 문구는 1과 그대로)
6. `# 함께 나누기          3 분` — 1과 문구 그대로 + `[[WRITING_BOX:1]]`
7. `# 교회의 고백과 잇기          3 분` — `[[BOX:WSC 제N문   <질문>]]` 답 인용 +
   `오늘 배운 <이 과의 주제어>와 이 고백은 어디서 만나는가? 한 줄로 쓴다.` + `[[WRITING_BOX:1]]`

### 3단계 안의 순서

1. `**① 1단계로 돌아가기     4 분**` — `1단계 ①의 여는 질문과 ②에 쓴 의문을 다시 읽는다. 오늘 읽고
   확인한 것이 그 답을 어떻게 바꾸었는가.` + 이 과의 여는 질문을 회수하는 빈칸 문장
   (1과 꼴: `나를 다스리던 것은 ________________ 이었다. 그런데 하나님이 왕이시라면 ________________ 이 달라져야 한다.`)
   + `[[WRITING_BOX:1]]` + `아직 풀리지 않았다면 그대로 두어도 된다. KQCI의 Q에 적은 질문을 교사가 다음 시간에 함께 다룬다.`
2. `**② 이번 주 한 걸음     5 분**` — spec 「고등부 적용」을 한 걸음 하나로 만들고, 그것을 실행할
   순간·자리를 미리 정하게 한다. `□` 3개 + `□ 내가 정한 순간 __________________________` +
   `왜 그 순간인가? 한 문장.` + `[[WRITING_BOX:1]]`
   유형별 — 서사형: 물어볼 순간 / 논쟁형: 그 주장을 만날 자리에서 할 한 마디 / 적용형: 실천 하나와 시점.
3. `**③ 암송과 기도     3 분**` — `[[BOX:암송 · <책 N:N>]]` 인용 +
   `**기도 (앞부분은 함께 읽고, 뒷부분은 내가 쓴다)**` + `[[BOX:]]` 기도 2문단.
   앞문단은 이 과 교리를 고백하는 2문장(버전 2 기도문에서 압축), 뒷문단은 고정 꼴:
   `오늘 가장 마음에 남는 것은 ________________ 입니다. 그래서 이번 주에 저는 ________________ 하겠습니다. 예수님의 이름으로 기도합니다. 아멘.`
4. `# 나의 확인` — `□` 6개 고정 꼴: 암송했다 / 여는 질문에 먼저 답하고 의문을 적었다 /
   찾기 ①②③에서 내 말로 쓰고 견주었다 / KQCI 네 칸을 채웠다 / 함께 나누기에서 읽어 주고
   이유를 말했다 / 이번 주 한 걸음(그 과의 것)을 하나 정했다. 과 고유 내용은 1·6번에 반영.

## 3. `teacher-notes.md` 지면 순서 (2과부터 고정)

1과 기준본의 「현행본과 달라진 곳」 「KQCI를 2단계에 둔 까닭」 「참여 장치 운영 요령」은
**1과 전용이다. 2과부터 만들지 않는다.** 나머지는 이 순서:

```
# COVER            ← 작은제목 "… (고 1)  |  교사 안내면  |  전주서문교회 교육부"
                     큰제목 "N 과   <주제> — 교사 안내" · 부제 "학생 배부본에서는 이 면 전체를 삭제한다."
# 수업 구성 한눈에 보기      [[TABLE:head+label]] 3행(1과 꼴, 이 과 내용으로) + 무게중심 문단
# 이 과에서 지킬 것          - 1)~N) 4~6개. 이 과 고유의 것 위주 — 버전 2의 「반드시 지킬 것」에서
                             이 과에만 해당하는 항목을 새 구조 용어(여는 질문·찾기·KQCI)로 바꿔 가져온다
# 찾기별 확인 도달 기준 (학생용 미인쇄)   [[TABLE:head+label]] | 찾기 | 구절 | 이 말이 나오면 도달 | 3행
                             + "근거를 못 대면 답을 고쳐 주지 말고 …" 한 줄 (버전 2 도달 기준·대응표에서)
# 교사가 말해 주는 것 (찾기 N에서만)   본문에 근거 구절이 없어 교사가 소리 내어 말해 줄 것 1~2개.
                             없으면 이 섹션을 만들지 않는다
# 예상 오답과 대응           - 1)~N) 4~6개 (버전 2에서 가져오되 "찾기 ①로 되돌린다"처럼 새 구조로 고쳐 쓴다)
# 시간 배분과 필기량         [[TABLE:head+label]] 4행(1과 꼴 그대로) + 줄이지 말 곳 · 필기량 문단
# 교사용 해설과 참고 구절    **읽기 주의** **탐구 질문 (교사 구두용)** **교사용 참고 구절** **연계** **본문 경계**
                             (버전 2의 집필·진행 메모 + 탐구 질문 답안 요지에서. 해당 없는 표제는 뺀다)
# 주요 대지 원문 (교사용 · 원천 그대로)   - ①~④ → 확인 N (spec 문장 그대로)
# FOOTER           ← "<주제> N 과 · 교사 안내면  |  고등부"
```

▣유의 과는 `# 정서 보호 지침`을 「수업 구성 한눈에 보기」 바로 뒤에 추가하고 spec 등급 지침을
그대로 옮긴다.

## 4. 블록 스킴 (렌더러가 읽는 표시)

| 표시 | 쓰는 곳 |
|---|---|
| `[[BOX:제목]] … [[/BOX]]` | 핵심 교리 문장 · 여는 질문 · 중심본문 · 찾기 구절 · 확인 N · WSC · 암송 · 기도 |
| `[[WRITING_BOX:N]]` | 필기 줄 (총 12줄, §1의 배치 고정) |
| `[[TABLE:label]]` | 정보표 |
| `[[TABLE:head+label]]` | 교사용 표 |
| `**굵게**` | ①②③ 소항목 제목 · 찾기 제목 · 낱말 표제 · KQCI 항목 |
| `□ 항목` | 여는 질문 선택지 · 이번 주 한 걸음 · 나의 확인 |
| `① ② ③` | 단계 안 소항목 · 찾기 번호 |

표 앞에 반드시 `[[TABLE:...]]` 줄. 마크다운 구분선 행(`|---|`) 금지. `[[NOTE:]]`는 v3 학생
지면에서 쓰지 않는다(읽기 주의가 교사면으로 갔다).

## 5. 문장 품질

- AI 티를 피한다. `~할 수 있습니다`, `중요합니다`, `살펴봅시다` 금지.
- 한 문단 2~4문장. 접속사로 문단을 시작하지 않는다.
- 여는 질문·이번 주 한 걸음은 고 1이 실제로 마주치는 자리에서(성적·입시·알고리즘·또래·가정·
  아르바이트·진로). 앞뒤 과와 같은 영역을 반복하지 않는다 — 버전 2가 이미 과별로 고른 영역을
  그대로 쓰면 된다.
- 학생을 채점하는 문장 금지. 신앙 상태 자가진단 문항 금지.
- 확인 해설을 압축할 때 "본문의 말을 짚는 문장"을 남긴다. 교리 요약문만 남기면 찾기가 죽는다.
