### 2. 순서 맞춰보기 🔢
본문 Q1~Q6에서 다룬 논리 흐름을 순서대로 번호를 매겨보세요. (본문 "말씀 속으로 한 걸음"을 다시 펼쳐 확인해도 좋아요.)

( ) 신약의 성례는 그리스도께서 말씀으로 제정하신 세례와 성찬, 딱 두 가지뿐이다.
( ) 성례는 반드시 그리스도께서 직접 제정하신 규례여야 참된 성례다.
( ) 세례는 그리스도와의 연합의 "시작"을, 성찬은 그 연합의 "계속"을 나타낸다.
( ) 성례의 효력은 집례자의 경건이나 표징 자체의 능력이 아니라 말씀과 성령의 역사에 달려 있다.
( ) 하나님은 말씀·성례·기도라는 은혜의 방편을 통해 우리 믿음을 자라게 하신다.
( ) 성례는 보이지 않는 은혜를 보이는 표징으로 "나타내고, 인치고, 적용"한다.

### 3. 나의 '성례 이해' 점검표 ✅
아래 문항에 체크해보세요.

□ 나는 세례가 나를 구원하는 게 아니라 이미 있던 믿음을 확증하는 것임을 알고 있다.
