새 교재 프로젝트를 생성한다. 아래 순서를 그대로 따른다.

## 1. 정보 수집

사용자에게 다음 항목을 확인한다. 사용자가 이미 메시지에서 언급한 항목은 다시 묻지 않는다. AskUserQuestion(가능하면) 또는 일반 질문으로 묻는다.

- 교재 제목
- 주제/목적 (무엇을 가르치는 교재인가)
- 대상 (연령·수준: 예. 중고등부, 청년부, 신입사원 등)
- 총 과 수
- 회당 수업 시간
- 과당 분량 기준 (기본값: A4 2~3장, 2,500~4,000자. 사용자가 다른 기준을 원하면 그대로 반영)
- 성경 인용 번역본 (기본값: 개역개정. 다른 번역을 명시적으로 요청하지 않는 한 개역개정만 사용)
- 필수 산출물 (기본값: 학생용 본문 + 활동지 + 교사용 해설, Word 파일 1순위)

## 2. 프로젝트 폴더 생성

교재 제목에서 짧은 kebab-case 영문 slug를 만들어 project-id로 쓴다 (예: "청소년 요한복음 교재" → `youth-john`). 다음 폴더를 만든다.

```
projects/<project-id>/
projects/<project-id>/style/
projects/<project-id>/lessons/
```

## 3. project.md 작성

`templates/project.md`가 있으면 그것을 복사해 채우고, 없으면 새로 작성한다. 1번에서 수집한 정보를 모두 포함하고, 다음 표를 반드시 넣는다.

과별 진행 현황표 (전체 과 수만큼 행 생성, 상태는 모두 "미시작"으로 시작):

| 과 | 주제 | 상태 |
|---|---|---|
| 01 | (미정) | 미시작 |
| 02 | (미정) | 미시작 |
| ... | ... | ... |

## 4. 안내

작업을 마치면 사용자에게 다음 단계는 `/design-lesson1`(1과 기준본 설계)임을 안내한다.
