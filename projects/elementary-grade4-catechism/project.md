# 다음세대 교리교육 · 초등 4학년 학생용 교재

## 프로젝트 개요

- 프로젝트 ID: `elementary-grade4-catechism`
- 대상: 초등학교 4학년
- 과 수: 40과
- 원천: 「다음세대 교리교육 · 초등부 120과 지침서」의 1년차 1–40과
- 교재 유형: 학생용 사고독해 교리 워크북
- 출력 프로필: `student-only`
- 판형: JIS B5 세로 182×257mm
- 과당 기본 분량: 4쪽
- 성경 번역: 개역개정
- 학년 사고 수준: 분석·연결

## 핵심 원칙

1. 이 프로젝트는 새 교리 내용을 창작하지 않는다. 원천 지침서의 과별 정본을 재구성한다.
2. 학생용에는 교사 메모·신앙고백 해설·흔한 오해·중등부 연결을 싣지 않는다.
3. 원천의 5단계 흐름은 유지한다.
   - 1단계 일상 스토리
   - 2단계 말씀 탐험
   - 3단계 빈칸·미션
   - 4단계 결단 액션
   - 5단계 말씀 이어가기
4. 오늘의 한 문장, 중심 본문, 원천 질문 2개, 미션, 결단, 말씀 이어가기, 암송은 정본으로 유지한다.
5. 읽기·사고 보강은 4학년 수준의 `분석·연결`에 한정한다. 키워드·핵심문장·관계·원인/결과·본문 근거 찾기를 사용하며 5학년의 개념 해석이나 6학년의 논증을 앞당기지 않는다.
6. 학생 직접 필기는 한 과 전체 8줄 이내로 관리한다. 표시·선택·연결·말하기를 우선한다.
7. 한 페이지 학습 텍스트는 400자를 넘기지 않는다.
8. 4학년 읽기 보강 본문은 180–230자를 기본 범위로 한다.
9. 빈칸은 한 과에 정확히 하나만 둔다.
10. `말씀 이어가기`는 부모 서명이나 수행 평가로 만들지 않는다. 부모/가족, 믿을 만한 어른, 교사, 혼자 기록 등 대체 선택을 허용한다.

## 조판 스타일

현재 승인 기준은 기존 「초등부 4–6학년 사고독해 교리교재 3개 샘플 완전판」의 4학년 1과 디자인 언어를 따른다.

- 상단 얇은 주황색 포인트 바
- 네이비 제목
- 주황색 학년/단계 포인트
- 연한 노랑·하늘색·흰색 라운드 박스
- 충분한 여백과 넓은 기록 공간
- 5단계 내비게이션을 매 페이지 상단에 반복
- 한 페이지에 주된 학습 행동 1개 중심
- 체크박스 남발 금지
- 과도한 장식보다 읽기·표시·연결 활동을 우선

## 4쪽 기본 페이지 역할

1쪽: 일상 스토리 + 오늘의 한 문장 + 분석·연결 읽기
2쪽: 키워드/핵심문장/관계 찾기 + 말씀 탐험
3쪽: 빈칸·미션 + 결단 액션 + 읽기에서 삶으로 연결
4쪽: 말씀 이어가기 + 암송 + 마지막 한 문장 설명

과별 활동 성격 때문에 공간 배분은 바꿀 수 있으나, 5단계와 4쪽 총량은 유지한다.
