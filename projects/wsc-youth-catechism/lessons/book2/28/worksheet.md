# 활동지 — 2권 제 28 과 (소요리문답 제 86 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채우며 오늘의 문답을 외워보세요.

문) 그리스도를 믿는 (　　　　)이란 무엇인가?
답) 그리스도를 믿는 믿음은 (　　　　)에 이르게 하는 은혜이니, 이로써 우리는 (　　　　)에 제시된 그리스도를 (　　　　)하고 오직 그분만을 (　　　　)하여 구원을 받는다.

## 2. 순서 맞춰보기 🔢
오늘 배운 "믿음"의 논리 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(　) 그 말씀이 참되다고 승인하고, 나에게 주신 것이라 확신하며 그리스도를 영접하고 의지한다.
(　) 성령께서 그 말씀을 통해 믿음을 우리 안에 만들어 가신다.
(　) 믿음은 은혜, 곧 하나님이 값없이 주시는 선물이다.
(　) 그리스도의 말씀을 들음으로 믿음이 시작된다.
(　) 그 믿음은 삶에서 사랑의 열매로 이어진다.

## 3. 나의 '믿음' 점검표 ✅
아래 문항에 솔직하게 체크해보세요.

□ 나는 믿음을 "내가 만들어내는 노력"보다 "받은 선물"로 더 자주 느낀다.
□ 나는 최근 한 달 안에 성경 말씀을 소리 내어 읽거나 들은 적이 있다.
□ 나는 그리스도를 "안다"는 것과 "의지한다"는 것의 차이를 구별해서 말할 수 있다.
□ 나는 믿음이 약해질 때 그리스도를 바라보기보다 스스로를 자책하는 편이다.

서술형: 위 네 문항 중 가장 마음에 걸리는 문항 하나를 고르고, 그 이유를 짧게 적어보세요.
