# 활동지 — 2권 제 23 과 (소요리문답 제 79 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 제 79 문을 완성해보세요.

문) 제10계명은 무엇인가?
답) 제10계명은 "네 이웃의 (        )을 탐내지 말라. 네 이웃의 (        )나 그의 남종이나 여종이나 (        )나 나귀나 무릇 네 이웃의 (        )를 탐내지 말라" 하신 것이다.

## 2. 순서 맞춰보기 🔢
오늘 "말씀 속으로 한 걸음"에서 다룬 논리를 순서대로 번호를 매겨보세요.

(  ) 바울은 로마서 7장에서 "탐내지 말라"는 이 계명 앞에서 자기 마음속 죄를 부인할 수 없었다고 고백한다.
(  ) 제10계명은 이웃에게 속한 것이라면 무엇이든(집, 아내, 종, 소, 나귀, 그 밖의 모든 소유) 다 포함한다.
(  ) "탐내는 것"은 스쳐 가는 부러움이 아니라, 이웃의 것을 내 것으로 만들고 싶어 하는 지속적인 욕망이다.
(  ) 살인·간음·도둑질·거짓 증거 같은 앞선 계명들이 겉으로 드러나는 행동을 다뤘다면, 이 계명은 그 행동의 뿌리인 마음을 다룬다.
(  ) 탐심은 마음의 자리에 하나님 대신 다른 것을 채우는 것이기에, 골로새서는 이를 "우상 숭배"라고까지 부른다.
