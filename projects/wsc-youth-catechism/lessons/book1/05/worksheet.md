# 활동지 5과 — 하나님의 삼위일체

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 하나님의 신격에는 몇 위가 계시는가?
답: 하나님의 신격에는 성부, 성자, ______________ 삼위가 계시니, 이 삼위는 한 하나님이시요 ______________가 동일하시며 능력과 ______________이 동등하시다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러므로 세 위격은 구별되나 결코 나뉘거나 분리되지 않는다.
( ) 성경은 성부, 성자, 성령을 나란히 하나님으로 증언한다(마 28:19, 고후 13:13).
( ) 하나님은 유일하고 자존하신 한 분이시며, 이 존재 자체를 "신격"이라 부른다.
( ) 성부, 성자, 성령은 능력과 영광에 있어서도 서로 종속되지 않고 완전히 동등하시다.
( ) 그런데 세 분은 서로 다른 신이 아니라 본질과 실체가 완전히 동일한 한 하나님이시다(동일본질).

## 3. 나의 '삼위일체 인식' 점검표 ✅

그동안 나는 성부, 성자, 성령을 어떻게 생각해왔는지 표시해보세요. (중복 가능)

- [ ] 세 분을 거의 다른 신처럼 따로 생각했다
- [ ] 성부보다 성자와 성령이 조금 낮은 분인 줄 알았다
- [ ] 기도할 때 한 분에게만 습관적으로 이야기했다
- [ ] 세 분이 한 하나님이시라는 걸 알지만 실감은 잘 안 났다
- [ ] 오늘 배우고 나서 처음으로 명확하게 정리됐다
