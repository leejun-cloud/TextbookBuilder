# Style Rules — 초등 4학년 학생용 교리교재

## 기준본

Golden Master: 1과 「하나님 나라는 어떤 나라일까요」 B5 4쪽 학생용.

## 분량

- 판형: JIS B5 182×257mm 세로
- 과당: 기본 4쪽
- 읽기 보강 본문: 180–230자
- 학생 직접 필기: 전체 8줄 이내
- 페이지 학습 텍스트: 400자 이내
- 말씀 탐험: 원천 질문 정확히 2개
- 빈칸: 정확히 1개

## 문체

- 초등 4학년에게 직접 말하는 `~예요 / ~해요`.
- 설명은 짧고 구체적으로 쓴다.
- 추상어보다 장면·행동·관계를 사용한다.
- 훈계보다 관찰·찾기·연결·선택을 사용한다.

## 사고 수준

4학년의 핵심은 `분석·연결`이다.

- 키워드 3–4개 찾기
- 핵심문장 판단하기
- 두 개 이상의 개념을 선·화살표·원인/결과로 연결하기
- 성경 본문에서 직접 근거 찾기
- 마지막에는 한 문장으로 생활과 연결하기

5학년식 개념 해석이나 6학년식 CER 논증을 필수 활동으로 올리지 않는다.

## 고정 페이지 리듬

### 1쪽 — 시작하고 읽기
- 오늘의 한 문장
- 1단계 일상 스토리
- 한 번의 선택/관찰
- 분석·연결 읽기 본문

### 2쪽 — 정리하고 말씀 찾기
- 키워드/관계 찾기
- 핵심문장 판단
- 2단계 말씀 탐험: 중심 본문 + 원천 질문 2개

### 3쪽 — 행동으로 연결하기
- 3단계 빈칸 1개
- 원천 미션
- 4단계 결단 액션
- 언제·어디서 등 구체화 최소 기록

### 4쪽 — 이어가고 기억하기
- 5단계 말씀 이어가기
- 대체 선택지
- 암송
- 오늘의 한 문장을 내 말로 설명

## 시각 스타일

- 상단 3mm 주황색 포인트 바
- 메인 제목 네이비
- 단계/학년 포인트 주황색
- 주요 정보 박스: 연한 하늘색·노랑·흰색
- 둥근 모서리와 가벼운 선
- 넓은 여백
- 페이지 상단에 5단계 내비게이션 반복
- 현재 단계만 주황색 활성화
- 본문·활동 영역은 장식보다 사용성을 우선
- 체크박스는 꼭 필요한 선택에서만 사용

## 원천 정합성

- 오늘의 한 문장 불변
- 중심 본문 장절 불변
- 원천 말씀 탐험 질문 2개 불변
- 미션·결단·말씀 이어가기·암송 의미 불변
- ◎ 필수암송 표시 유지
- 교사 메모는 학생용 출력 금지
