## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그래서 하나님은 자기 진리를 더 잘 보존하시려고 계시를 문자로 기록하게 하셨다.
( ) 일반계시(자연·양심)만으로는 타락한 우리가 구원에 필요한 지식을 얻을 수 없다.
( ) 성령의 감동을 받은 사람들이 기록한 66권이 정경으로 확정되었다.
( ) 성경을 기록하신 성령이 지금 우리가 읽을 때도 동일하게 역사하신다.
( ) 그러므로 성경만이 우리 삶의 유일하고 확실한 기준이 된다.
