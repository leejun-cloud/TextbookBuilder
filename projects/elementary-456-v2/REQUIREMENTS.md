# 요구사항 대조표 — 사용자 지시 원문과 검증 방법

각 단계(파일럿 → 배치 → 최종 산출) 끝에서 이 표를 대조한다. 최종 보고에 결과를 붙인다.

| # | 요구사항 (사용자 지시) | 검증 방법 | 파일럿 | 최종 |
|---|---|---|---|---|
| 1 | 담임목사 표준안(1·41·81과)을 기준본으로 한다 | qc 원천 일치 + fixture 4과 고정 | ✓ fixture 4과 고정·qc 원천일치 | ✓ 원천·기준본 대조 통과 |
| 2 | 디자인은 B5 번들의 시각 스타일, 학년 색(초록/파랑/자주) | 빌더 golden test + PDF 시각 확인 | ✓ 빌더 golden test + g5 파랑 시각 확인 | ✓ 3권 모드 라벨·색 확인(4초록/5파랑/6자주) |
| 3 | **교사용 쪽 제거** — 학생용 3쪽만 | 과별 PDF 쪽수 = 3 | ✓ 과별 PDF 3쪽 | ✓ 전 과 3쪽 (권당 123쪽 = 표지1+차례1+사용법1+40×3) |
| 4 | **읽기(성경 해석)가 학년이 올라갈수록 길어진다** — 4: 300–430 / 5: 420–560 / 6: 540–720자, 문단 2/2/3 | qc READ_BAND | ✓ qc 밴드 16과 통과 | ✓ qc 120과 밴드 통과 (검수가 5학년 4과 보강) |
| 5 | 4학년도 읽기가 충분해야 한다 (승인 샘플 수준) | qc 하한 300자 + 학년 검수 | ✓ 하한 300자 통과 | ✓ 4학년 40과 하한 통과 |
| 6 | **충분한 내용으로 아이에게 실제 도움이 되는 교재** — 흔한 오해 교정 내장, 지시문 조립·문장 반복(옛 번들의 실패) 금지 | 학년 교리 검수 레인 + qc DUP + 지휘자 표본 정독 | ✓ 표본 정독(g4-3 삼위일체·g6-5 성령의 열매) — 오해 교정 내장, 반복 없음 | ✓ 교리 검수 40여 건 수정 (양태론·기념설·회심혼동 등) + DUP 0 |
| 7 | 성경 인용은 개역개정, 지어내지 않는다 | qc 인용 부분문자열 검증 (검증 코퍼스 1,769건) | ✓ 코퍼스 검증 + fact 케이스 규칙화 | ✓ 인용미확정 0 · 창 9:6 오인용 발견·정정 + 코퍼스 차단 |
| 8 | 원천(지침서 120과) 충실 — 한 문장·질문·빈칸·암송·과번호 | qc 원천 일치 | ✓ qc 통과 | ✓ qc 120과 통과 |
| 9 | 유의 과 배려 (발표·수거 금지 등) | qc sensitivity + 학년 검수 | – 파일럿에 유의 과 없음 | ✓ 유의 과 문구 반영 (발표·수거 금지) |
| 10 | 3권 완전교재 (표지+차례+사용법+40과, JIS B5) | 권 PDF 쪽수·구성 확인 | – 최종 단계 | ✓ 3권 PDF 생성·시각검수·다운로드 전달 |
| 11 | 어투 ~예요/~해요, 점수·서열 문구 금지 | qc 어투 + 고정 각주 | ✓ qc 통과 | ✓ qc 어투 통과 |

기록 규칙: 통과 `✓ (근거)`, 실패 `✗ → 조치`.
