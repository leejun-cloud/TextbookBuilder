## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그 도덕법은 시내 산에서 십계명이라는 구체적인 열 마디로 주어지고, 두 돌판에 새겨졌다.
( ) 도덕법은 하나님이 아담에게 처음부터 심어 주신, 영원하고 변하지 않는 규범이다.
( ) 십계명의 첫 네 계명은 하나님 사랑을, 나머지 여섯 계명은 이웃 사랑을 가르친다.
( ) 율법 자체는 여전히 거룩하고 의롭고 선하지만, 죄 때문에 우리에게 정죄로 다가온다.
( ) 결국 십계명을 안다는 것은 규칙을 외우는 게 아니라 하나님의 성품을 알고 닮아가는 것이다.

## 3. 나의 '규칙의 뿌리' 점검표 ✅

지난 한 주, 내가 지키려고 애썼던 규칙이나 다짐에 표시해보세요. (중복 가능)

- [ ] 예배·기도 시간을 지키려 함
- [ ] 거짓말하지 않으려 함
- [ ] 부모님(웃어른)께 순종하려 함
- [ ] 친구를 험담하지 않으려 함
- [ ] 남의 물건이나 시간을 함부로 대하지 않으려 함
- [ ] 기타: ___________

→ 위에서 표시한 것 중, 그 뿌리가 "하나님 사랑"에 가까운 것과 "이웃 사랑"에 가까운 것을 하나씩 골라 적어보세요.
