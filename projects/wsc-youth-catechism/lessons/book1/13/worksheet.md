## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 죄가 무엇인가?
답: 죄는 하나님의 율법을 조금이라도 ______________하게 지키거나 그 법을 ______________ 것이다.

문: 우리의 첫 조상이 창조받은 상태에서 타락하게 된 죄는 무엇인가?
답: 우리의 첫 조상이 창조받은 상태에서 타락하게 된 죄는 하나님께서 ______________ 금하신 ______________를 먹은 것이다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그런데 이 언약의 핵심은 열매 자체가 아니라 창조주께 대한 무조건적 순종을 확인하는 데 있었다.
( ) 죄는 본성의 결핍이 아니라, 자유의지로 선택한 불순종의 행위다.
( ) 첫 조상은 하나님께서 먹지 말라고 금하신 열매를 먹었다.
( ) 그 죄 안에는 불순종, 배은망덕, 교만이 함께 들어있었다.
( ) 그 결과 죄책과 오염이 아담에게 그대로 임하여, 하나님과 거닐던 존재가 하나님을 피해 숨는 존재가 되었다.

## 3. 나의 '이 정도쯤이야' 점검표 ✅

지난 한 주, 오늘 배운 죄의 정의(부족하게 지킴 / 어김)에 비추어 나를 돌아보며 표시해보세요. (중복 가능)

- [ ] 해야 할 일을 알면서도 대충 미루거나 건성으로 함 (부족하게 지킴)
- [ ] 하지 말아야 할 일인 줄 알면서도 그대로 함 (어김)
- [ ] "다들 이 정도는 그냥 넘어가니까"라며 스스로를 정당화함
- [ ] 부족함이 없는데도 더 갖고 싶은 것 하나에 마음을 뺏김 (배은망덕)
