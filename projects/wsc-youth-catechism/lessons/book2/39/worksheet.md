## 2. 순서 맞춰보기 🔢

본문 Q1~Q6의 논증 흐름을 떠올리며, 아래 문장들을 올바른 순서대로 번호(1~5)를 매겨보세요.

(　) 기도는 하나님의 온 말씀에서 유익을 얻지만, 그리스도께서 직접 가르치신 주기도가
    특별한 지침으로 주어졌다.
(　) 참된 기도에는 구함뿐 아니라 죄의 고백과 하나님의 자비에 대한 감사가 함께 담긴다.
(　) 기도는 살아계셔서 실제로 들으시는 하나님께 소원을 아뢰는 것이다.
(　) 우리는 마땅히 기도할 바를 스스로 알지 못하므로, 그리스도께서 본을 직접 주셨다.
(　) 우리의 기도는 그리스도의 이름으로, 그의 의를 힘입어 하나님께 상달된다.

## 3. 나의 '기도 생활' 점검표 ✅

아래 항목 중 최근 한 달 내 나에게 해당하는 것에 체크해보세요.

□ 나는 무언가를 구할 때만 기도한다.
□ 나는 기도할 때 죄를 구체적으로 고백한 적이 있다.
□ 나는 구함 없이 오직 감사만 드리는 기도를 해본 적이 있다.
□ 나는 "그리스도의 이름으로 기도합니다"라는 말의 의미를 생각하며 기도를 마친 적이 있다.
□ 나는 주기도문을 스스로 천천히 읽거나 묵상해본 적이 있다.
