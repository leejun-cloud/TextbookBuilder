# 활동지 3과 — 성경이 나에게 가르치는 두 가지

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 성경이 주로 가르치는 것이 무엇인가?
답: 성경이 주로 가르치는 것은 사람이 하나님에 대하여 마땅히 ______________할 것과, 하나님이 사람에게 요구하시는 ______________이 무엇인가 하는 것이다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) '본분'은 그 하나님 앞에서 우리가 마땅히 해야 할 삶의 의무, 곧 순종이다.
( ) '믿어야 할 것'은 하나님이 어떤 분이시고 무엇을 하셨는지에 대한 지식이다.
( ) 본분 없는 믿음은 교만한 지식으로, 믿음 없는 본분은 억지 율법주의로 흐른다.
( ) 성경은 이 두 가지를 항상 함께 다뤄서, 아는 만큼 살고 사는 만큼 더 깊이 알게 한다.
( ) 그러므로 성경을 읽을 때는 "무엇을 믿어야 하는가"와 "무엇을 해야 하는가"를 함께 물어야 한다.

## 3. 나의 '믿음·본분' 점검표 ✅

지난 한 주, 성경을 읽거나 신앙생활을 하면서 나에게 더 익숙했던 쪽에 표시해보세요. (중복 가능)

- [ ] 성경 지식·교리를 배우는 것
- [ ] 배운 대로 실제로 행동하는 것
- [ ] 둘 다 균형 있게 하고 있다
- [ ] 사실 둘 다 잘 안 하고 있다
- [ ] 기타: ___________

→ 위에서 표시한 것 중, '믿음'과 '본분'이 따로 놀고 있다고 느끼는 부분이 있다면 무엇인가요?
