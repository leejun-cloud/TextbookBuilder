답) 생명에 이르는 회개는 (　　　　　　)에 이르게 하는 은혜이니, 죄인이 자기 죄를 (　　　　　　) 깨닫고 그리스도 안에 있는 하나님의 (　　　　　　)를 깨달아, 자기 죄를 (　　　　　　) 미워하여 죄에서 돌이켜 하나님께로 향하며, 새롭게 (　　　　　　)하려는 온전한 목적과 노력으로 결심하는 것이다.

### 2. 순서 맞춰보기 🔢
오늘 문답 안에 들어 있는 회개의 다섯 단계입니다. 본문(3번 섹션)을 다시 보며 올바른 순서대로 번호(1~5)를 매겨보세요.

(　　) 새롭게 순종하려는 온전한 목적과 노력으로 결심함
(　　) 자기 죄를 참으로 깨달음
(　　) 자기 죄를 슬퍼하고 미워함
(　　) 그리스도 안에 있는 하나님의 자비를 깨달음
(　　) 죄에서 돌이켜 하나님께로 향함

### 3. 나의 회개 점검표 ✅
아래 항목에 해당하면 체크해보세요.

□ 나는 내 죄를 "죄"라고 정확히 인식한 적이 있다 (지성적 요소)
□ 나는 그 죄 때문에 마음속으로 진심으로 슬퍼해본 적이 있다 (정서적 요소)
□ 나는 그 죄를 떠나기로 실제로 결단하고 방향을 바꿔본 적이 있다 (의지적 요소)
□ 나는 회개를 "내가 애써서 하는 반성"이 아니라 "하나님이 주시는 은혜"로 받아들여본 적이 있다
□ 나는 한 번의 결심으로 끝내지 않고, 같은 문제로 계속 하나님께 돌아온 적이 있다
