문) 제10계명이 요구하는 것은 무엇인가?
답) 제10계명이 요구하는 것은 자기 처지에 (        ) 만족하고, 이웃과 그의 모든 소유에 대하여 (        )하고 (        )한 마음을 품는 것이다.

문) 제10계명이 금하는 것은 무엇인가?
답) 제10계명이 금하는 것은 자기 처지에 조금이라도 (        )하지 못하는 것과, 이웃이 잘되는 것을 (        )하거나 (        )하는 것과, 이웃의 소유에 대하여 조금이라도 부당한 마음이나 (        )을 품는 것이다.

## 2. 순서 맞춰보기 🔢
오늘 "말씀 속으로 한 걸음"에서 다룬 논리를 순서대로 번호를 매겨보세요.

(  ) 이웃이 잘되는 것을 시기하거나 근심하는 것도, 방향은 다르지만 욕심과 같은 뿌리에서 나온다.
(  ) 아담과 하와는 부족한 것이 하나도 없었지만 맹목적인 욕심으로 하나님과 같이 되고자 했다.
(  ) 6-9계명은 겉으로 드러난 행동을 다루지만, 10계명은 그 행동이 시작되는 마음 자체를 다룬다.
(  ) "조금이라도"라는 표현은, 아직 행동으로 옮기지 않은 작은 불만족조차 이미 죄라는 것을 보여준다.
(  ) 이웃 사랑의 완성은 손해를 끼치지 않는 데서 그치지 않고, 이웃의 행복을 진심으로 기뻐하는 데까지 나아간다.
