## 2. 순서 맞춰보기 🔢

( ) 하나님은 독생자 예수님을 하나님과 사람 사이의 중보자로, 그리고 선지자와 제사장과 왕으로 택하고 임명하셨다.
( ) 세 직분은 서로 구별되지만 늘 함께 작용하여, 한 사건 안에 세 직분이 동시에 담겨 있다.
( ) 선지자직은 하나님의 뜻과 진리를 알리고 그대로 이루시는 직분이다.
( ) 제사장직은 자기 자신을 제물로 드리시고 우리를 위해 중재·기도하시는 직분이다 — 이 '올려드림'이 없으면 왕의 '내려주심'도 없다.
( ) 왕직은 자기 자신을 우리에게 내려주셔서 성령으로 우리 안에 사시며 다스리는 직분이다.
