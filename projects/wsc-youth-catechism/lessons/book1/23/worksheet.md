## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 제사장은 백성을 대신해 하나님 앞에 서서, 제사를 드리고 중재하는 두 가지 일을 한다.
( ) 그리스도는 자기 자신을 제물로 삼아 단번에 영원한 제사를 드리셨다.
( ) 제사를 드리는 제사장과 드려지는 제물이 하나가 되어, 하나님의 공의가 온전히 만족되었다.
( ) 원수 되었던 우리가 하나님의 자녀요 상속자로 화목하게 되었다.
( ) 그리스도는 지금도 하나님 우편에서 우리를 위해 계속 간구하고 계신다.
