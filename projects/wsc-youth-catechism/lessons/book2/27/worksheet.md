# 활동지 — 2권 제 27 과 (소요리문답 제 85 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 제 85 문을 완성해보세요.

문) 우리의 죄로 마땅히 받아야 할 하나님의 진노와 저주를 피하기 위해 하나님께서 우리에게 요구하시는 것은 무엇인가?
답) 하나님께서는 우리에게 그리스도를 (　　　　　)와 생명에 이르는 (　　　　　)와, 그리스도께서 구속의 은택을 전달하시는 모든 (　　　　　　)을 부지런히 사용할 것을 요구하신다.

## 2. 순서 맞춰보기 🔢
오늘 본문(말씀 속으로 한 걸음)에서 다룬 논리의 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(　) 하나님은 진노와 저주를 피할 길을 우리에게 "요구"하시지만, 그것은 대가가 아니라 이미 마련된 구원을 받는 통로다.
(　) 첫째, 그리스도를 믿는 믿음은 성령께서 값없이 주시는 은혜의 선물이다.
(　) 둘째, 생명에 이르는 회개는 믿음과 짝을 이루어 죄에서 돌이켜 하나님께로 돌아오는 것이다.
(　) 셋째, 하나님은 말씀·성례·기도라는 외적 방편을 통해 구속의 은택을 우리에게 전달하신다.
(　) 그러므로 믿음, 회개, 외적 방편을 부지런히 사용하는 것은 억지 의무가 아니라 은혜에 대한 자연스러운 반응이다.

## 4. 한 문장으로 설명하기 🗣️
"교회 다니는 사람들은 왜 성경 읽고, 예배드리고, 기도하는 걸 그렇게 강조해요? 그게 구원이랑 무슨 상관이에요?"라고 묻는 친구에게, 오늘 배운 내용(믿음·회개·외적 방편은 조건이 아니라 하나님의 은혜를 누리는 통로라는 것)을 한두 문장으로 설명해보세요.
