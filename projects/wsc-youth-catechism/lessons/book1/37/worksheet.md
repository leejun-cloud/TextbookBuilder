## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 사람을 창조하실 때 이미 도덕법을 마음에 심어 순종을 요구하셨다.
( ) 도덕법은 십계명 속에 하나님 사랑(1-4계명)과 이웃 사랑(5-10계명)으로 담겨 있다.
( ) 사람이 타락한 뒤에도 도덕법 자체는 조금도 변하지 않고 그대로 유효하다.
( ) 타락 이후 도덕법은 우리가 얼마나 그 기준에 미치지 못하는지 비춰주는 거울 역할도 한다.
( ) 그리스도를 믿는 신자에게도 도덕법은 정죄가 아니라 삶의 규범으로 여전히 유용하다.
