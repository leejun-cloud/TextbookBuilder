## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 그리스도 안에서 의롭다 칭함을 받은 모든 자에게 자녀 삼으심의 은혜에 동참하도록 값없이 호의를 베푸신다.
( ) 그 은혜로 우리는 종의 영이 아니라 양자의 영을 받아, "아빠 아버지"라고 부르짖게 된다(롬 8:15).
( ) 자녀가 된 우리는 긍휼과 보호와 공급을 받고, 징계는 받으나 결코 내침을 당하지 않는다.
( ) 우리는 그리스도와 "함께" 상속자가 되어, 그와 함께 영광을 받기 위해 고난도 함께 받는다(롬 8:17).
( ) 성령이 우리 자녀 됨의 확실한 보증과 인이 되셔서, 이 확신은 소멸되지 않는다(엡 1:14).
