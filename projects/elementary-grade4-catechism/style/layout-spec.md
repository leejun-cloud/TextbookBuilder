# Layout Spec — B5 4쪽 학생용

## 판형

- JIS B5: 182×257mm
- 세로형
- 기본 안전 여백: 좌우 13mm, 상단 10–13mm, 하단 10mm
- 인쇄용으로 전면 배경/이미지가 재단선까지 갈 경우 3mm 도련 적용

## 공통 헤더

- 상단 주황색 3mm 바
- 왼쪽: `다음세대 교리교육 · 초등부 사고독해 교재`
- 오른쪽: 현재 페이지 역할
- 학년 캡슐 + 과 번호/연차/공통번호/필수암송 표시
- 과 제목
- 5단계 내비게이션

## 1쪽

상단 핵심문장 박스 → 일상 스토리 → 짧은 선택/관찰 → 180–230자 읽기.

## 2쪽

키워드/관계 찾기 → 핵심문장 판단 → 말씀 탐험 중심본문 → 원천 질문 2개.

## 3쪽

빈칸 1개 → 원천 미션 → 쓰기/기록 공간 → 결단 액션 → 삶으로 연결.

## 4쪽

말씀 이어가기 → 대체 참여 선택 → 암송 → 마지막 한 문장 설명.

## 타이포

- 메인 제목: 18–20pt Bold
- 섹션 제목: 11–13pt Bold
- 학습 본문: 8.5–10pt, 충분한 행간
- 핵심문장/암송: 10.5–12.5pt Bold
- 7pt 미만의 학습 본문 사용 금지

## 조판 실패 조건

- 텍스트 오버플로 또는 잘림
- 박스 안 텍스트가 테두리에 붙음
- 학습 본문을 억지로 축소해 7pt 미만으로 만듦
- 페이지별 텍스트 400자 초과
- 과도한 빈 공간 때문에 내용이 앞쪽에 몰림
- 선택/체크 장치가 학습 행동보다 더 눈에 띔
