## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 하나님은 엿새 동안 천지를 창조하시고 일곱째 날에 안식하시며, 그날을 복되고 거룩하게 하셨다.
( ) 이 창조의 질서에 근거해, 하나님은 말씀으로 "칠 일 중 하루"를 안식일로 정하여 지키게 하셨다.
( ) 그리스도께서 부활하신 후, 그 정해진 하루는 주간의 마지막 날에서 첫째 날(주의 날)로 바뀌었다.
( ) 이 하루는 세속적인 생업과 오락에 관한 일과 말과 생각을 멈추고, 예배와 자비의 의무로 채워야 한다.
( ) 그러므로 제4계명은 이 정해진 하루를 "온전히" 하나님께 거룩한 안식일로 지킬 것을 요구한다.

## 3. 나의 '한 주 중 하루' 점검표 ✅

- [ ] 전날 미리 일정을 정돈해서, 그날 마음을 예배에 집중할 준비를 한다
- [ ] 예배 시간 외에는 다른 날과 크게 다르지 않게 보낸다 (공부, 알바, 약속 등)
- [ ] 그날도 습관처럼 SNS·게임·쇼핑 등 오락에 상당한 시간을 쓴다
- [ ] 예배 외에 말씀 묵상이나 기도, 봉사·긍휼의 시간을 따로 갖는다
- [ ] 솔직히 "쉬는 날"과 "거룩하게 지키는 날"을 구분해본 적이 별로 없다
- [ ] 기타: ___________
