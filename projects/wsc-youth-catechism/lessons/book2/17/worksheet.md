## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러므로 제7계명이 요구하는 순결은 마음, 눈, 몸, 말까지 포함하는 전인격적인 문제다.
( ) 예수님은 실제 행위 이전에, 음욕을 품는 마음에서 이미 간음이 시작된다고 말씀하셨다(마 5:27-28).
( ) 하나님은 결혼을 상호 도움과 자손, 그리고 부정을 방지하기 위한 창조의 질서로 세우셨다.
( ) 그래서 순결은 결혼한 사람만이 아니라 약혼한 사람, 그리고 아직 결혼하지 않은 사람에게도 요구된다.
( ) "간음하지 말라"는 짧은 금지 뒤에는 실은 "관계와 가정을 지키고 보호하라"는 적극적인 부르심이 있다.
