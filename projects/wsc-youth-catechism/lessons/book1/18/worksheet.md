# 활동지 18과 — 하나님의 구원 계획(은혜언약)

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 하나님께서는 모든 인류를 죄와 비참의 상태에서 멸망하도록 버려두셨는가?
답: 하나님께서는 오직 자기의 선하신 ______________을 따라 ______________부터 어떤 사람들을 택하여 영생에 이르게 하시고, ______________을 맺으사 그들을 죄와 비참의 상태에서 건지사 ______________로 말미암아 구원의 상태로 이끄시기를 기뻐하셨다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 아담의 타락으로 첫 언약(행위언약)을 통해서는 아무도 생명을 얻을 수 없게 되었다.
( ) 하나님은 오직 자신의 기뻐하심을 따라, 영원 전부터 어떤 사람들을 택하셨다.
( ) 하나님은 온 인류를 죄와 비참 속에 그대로 멸망하도록 버려두지 않으셨다.
( ) 하나님은 은혜언약을 맺으사 그리스도를 통한 생명과 구원을 값없이 주기로 약속하셨다.
( ) 하나님은 구속자로 말미암아 택하신 자들을 구원의 상태로 이끄시기를 기뻐하셨다.

## 3. 나의 '자격' 점검표 ✅

나는 구원이 시작된 이유를 은근히 어디에 두고 있었는지 표시해보세요. (중복 가능)

- [ ] 내가 열심히 교회 다니고 노력했으니까
- [ ] 내가 부족해도 하나님이 먼저 은혜를 베푸셨으니까
- [ ] 내가 믿음이 강해서
- [ ] 나도 잘 모르겠고 그냥 자연스럽게
- [ ] 부모님·가족의 신앙 덕분에
- [ ] 기타: ___________

→ 위에서 표시한 것 중, 오늘 배운 "오직 자기의 선하신 기뻐하심을 따라"라는 말과 부딪히는 생각이 있었다면 무엇인가요?
