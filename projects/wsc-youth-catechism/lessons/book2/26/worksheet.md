# 활동지 — 2권 제 26 과 (소요리문답 제 84 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 제 84 문을 완성해보세요.

문) 모든 죄가 받아 마땅한 것은 무엇인가?
답) 모든 죄는 (　　　　　)와 (　　　　　)에서 하나님의 (　　　　　)와 (　　　　　)를 받아 마땅하다.

## 2. 순서 맞춰보기 🔢
오늘 본문(말씀 속으로 한 걸음)에서 다룬 논리의 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(　) 죄로 인해 사람은 하나님의 진노와 율법의 저주 아래 매이게 된다.
(　) 원죄든 실질적 죄든, 모든 죄는 하나님의 법을 범하는 것으로서 그 자체로 죄책을 낳는다.
(　) 그 결과는 영적 사망, 현세적 사망, 영원한 사망, 곧 "이생과 오는 세상"의 비참으로 이어진다.
(　) 율법은 단 하나의 예외도 봐주지 않으므로, 완전히 지키지 못한 모든 사람은 저주 아래 있다.
(　) 이 무거운 사실을 정직하게 알 때, 그리스도께서 대신 치르신 값이 얼마나 큰지 비로소 실감하게 된다.

## 4. 한 문장으로 설명하기 🗣️
