## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 아담과 하와는 하나님의 낯을 피하여 숨는 존재가 되었고, 하나님과의 교제가 끊어졌다.
( ) 죄에는 죄책이 따르므로, 인류는 하나님의 진노와 율법의 저주 아래 매이게 되었다.
( ) 땅이 저주를 받아 사람은 수고와 땀, 고통 속에서 살아가게 되었다.
( ) 이 땅에서의 삶이 끝나면 영혼과 몸이 분리되는 육체적 죽음을 맞이하게 된다.
( ) 회개하지 않은 자는 최후 심판 때 지옥에서 영원한 형벌을 받게 된다.

## 3. 나의 '비참함' 마주하기 ✅

오늘 배운 네 가지 항목을 다시 읽고, 평소 내가 얼마나 심각하게 느껴왔는지 표시해보세요.

- [ ] 하나님과의 교제 상실 — 하나님과 멀어진 것을 심각하게 느껴본 적이 있다
- [ ] 하나님의 진노와 저주 — 내 죄에 정당한 책임이 따른다는 걸 실감해본 적이 있다
- [ ] 이 세상의 고난 — 내가 겪는 수고와 아픔을 타락의 흔적으로 생각해본 적이 있다
