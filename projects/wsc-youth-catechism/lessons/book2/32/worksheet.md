## 2. 순서 맞춰보기 🔢
90문의 답을 여섯 단계로 쪼개 보면 아래와 같습니다. 본문 Q1~Q6의 설명을 떠올리며, 씨 뿌리는 비유(마 13:19, 23)에 빗대어 각 단계가 일어나는 순서대로 번호(1~6)를 매겨보세요.

(   ) 마음에 새겨 오래 두고 곱씹는다 — 두고두고 꺼내 쓰는 양식으로 삼는다
(   ) 삶에서 실천하여 열매를 맺는다 — 백 배, 육십 배, 삼십 배의 결실
(   ) 부지런함과 준비함으로 마음의 땅을 고른다 — 길가처럼 굳지 않게
(   ) 믿음과 사랑으로 받아들인다 — 듣기만 하고 자신을 속이지 않는다
(   ) 기도로 임한다 — "제 마음의 눈을 열어주세요"
(   ) 말씀을 읽거나 듣는다 — 씨가 뿌려지는 순간

## 3. 나의 '말씀 받는 태도' 점검표 ✅
아래 여섯 문항에 솔직하게 체크해보세요.

□ 성경을 읽거나 설교를 듣기 전, 마음을 미리 준비한다 (부지런함·준비함)
□ 말씀을 대하기 전에 짧게라도 기도한다 (기도)
□ 들은 말씀을 "나와 상관없는 이야기"가 아니라 "내 삶의 진실"로 받아들인다 (믿음)
□ 말씀을 억지 규칙이 아니라 나를 사랑하시는 하나님의 말씀으로 받아들인다 (사랑)
□ 인상 깊은 말씀을 며칠, 몇 주가 지나도 다시 떠올린다 (마음에 새김)
□ 들은 말씀을 실제 행동으로 옮긴 적이 최근 한 달 안에 있다 (실천)
