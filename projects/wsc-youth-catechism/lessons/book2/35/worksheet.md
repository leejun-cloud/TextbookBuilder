# 활동지 — 2권 제 35 과 (소요리문답 제 94 문)
## 세례

### 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 94문을 완성해보세요.

문) 세례가 무엇인가?
답) 세례는 물로 씻는 성례이니, ( ① )와 ( ② )와 ( ③ )의 이름으로 씻음으로써 우리가 그리스도께 ( ④ ) 되고 은혜언약의 유익에 참여하며 ( ⑤ )의 것이 되기로 ( ⑥ )함을 나타내고 인친다.

---

### 2. 순서 맞춰보기 🔢
본문 Q1~Q6에서 다룬 논리 흐름을 순서대로 번호를 매겨보세요. (본문 "말씀 속으로 한 걸음"을 다시 펼쳐 확인해도 좋아요.)

( ) 세례는 그리스도께서 직접 제정하신 성례이지, 사람이 만든 씻음 의식이 아니다.
( ) 세례를 받았다는 것은 나에게 구원하는 표, 거듭남의 표, 그리스도와 하나 됨의 보증이라는 세 가지 유익이 있다는 뜻이다.
( ) 세례의 효력은 물 자체가 아니라 그리스도와 성령의 역사에서 나오므로, 세례가 곧 구원을 자동으로 보장하지는 않는다.
( ) 세례는 삼위일체 하나님의 이름으로 거행되며, 성부의 사랑·성자의 의·성령의 역사를 함께 나타낸다.
( ) 세례는 내가 그리스도께 접붙여지고 은혜언약의 유익에 참여한다는 것을 나타내고 인친다.
( ) 세례는 하나님의 선언(주의 것으로 삼으심)이면서 동시에 나의 응답(주의 것으로 살겠다는 서약)이다.

---

### 3. 나의 '세례 이해' 점검표 ✅
아래 문항에 체크해보세요.

□ 나는 세례가 나를 자동으로 구원하는 것이 아님을 알고 있다.
□ 나는 세례가 아무 의미 없는 형식적 절차가 아니라, 그리스도께 접붙여졌다는 것을 인치는 사건임을 알고 있다.
□ 나는 세례를 "주의 것으로 살겠다"는 나의 서약으로도 받아들이고 있다.
□ 나는 세례의 유익 세 가지(구원하는 표, 거듭남의 표, 그리스도와 하나 됨의 보증)를 설명할 수 있다.
