# 활동지 35과 — 죽을 때 받는 은택

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 신자가 죽을 때에 그리스도에게서 받는 은택은 무엇인가?
답: 신자는 죽을 때에 그 영혼이 온전히 ______________되어 즉시 ______________에 들어가고, 그 몸은 여전히 그리스도와 ______________한 채로 부활 때까지 무덤에서 쉰다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 몸은 흙으로 돌아가고, 영혼은 그것을 주신 하나님께로 곧장 돌아간다.
( ) 죽음은 존재의 끝이 아니라, 영혼과 몸이 갈라지는 사건일 뿐이다.
( ) 신자의 영혼은 죽는 즉시 온전히 거룩해져 그리스도와 함께 있게 된다.
( ) 그 몸은 여전히 그리스도와 연합한 채로 무덤에서 잠자듯 쉰다.
( ) 영혼은 몸이 다시 살아나 하나가 될 부활의 날을 소망 중에 기다린다.

## 3. 나의 '죽음을 대하는 태도' 점검표 ✅

죽음이라는 단어를 생각할 때 나에게 실제로 드는 감정이나 생각에 표시해보세요. (중복 가능)

- [ ] 막연한 두려움이 든다
- [ ] 생각하고 싶지 않아서 피한다
- [ ] 사랑하는 사람과의 이별이 가장 두렵다
- [ ] 그리스도와 함께 있을 것이라는 확신이 있다
- [ ] 잘 모르겠고, 별로 생각해본 적이 없다
- [ ] 기타: ___________

→ 오늘 배운 소요리문답 37문의 내용이, 위에서 표시한 나의 태도를 어떻게 바꿔줄 수 있을까요?
