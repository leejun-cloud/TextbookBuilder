답) 제6계명이 금하는 것은 자기 생명이나 이웃의 생명을 (         ) 빼앗거나, 그렇게 (         ) 이끄는 모든 것이다.

## 2. 순서 맞춰보기 🔢
오늘 배운 논증의 흐름입니다. 순서대로 번호(1~5)를 매겨보세요.

(  ) 말과 태도, 미움을 품는 것도 생명을 해치는 이 계명의 위반에 포함된다.
(  ) 예수님은 살인이 마음속 미움과 분노에서 이미 시작된다고 말씀하셨다(마 5:21-22).
(  ) 사람은 하나님의 형상대로 지음받았기에, 자기 생명도 자기 마음대로 할 수 없다.
(  ) "부당하게" 빼앗는 것만 금지되며, 정당한 사법 절차나 정당방위는 여기 해당하지 않는다.
(  ) 이 계명은 결국 이웃의 생명을 보존하고 세워주려는 실제적 노력을 요구한다.

## 3. 나의 '말과 마음' 점검표 ✅
아래 항목 중 최근 나에게 해당하는 것에 표시해보세요.

□ 운전 중이나 게임 중에 순간적으로 거친 욕설이 튀어나온 적이 있다.
□ SNS나 단톡방에서 누군가를 비꼬거나 조롱하는 댓글을 남긴 적이 있다.
□ 화가 난 채로 하루를 넘기며 그 마음을 계속 품고 있었던 적이 있다.
□ 누군가를 뒤에서 험담하거나 그 자리에 없는 사람 이야기를 나쁘게 한 적이 있다.
□ 내 몸이나 마음을 소홀히 방치하거나 위험한 행동에 무모하게 나 자신을 던진 적이 있다.

서술형: 위 항목 중 가장 마음에 걸리는 것 하나를 골라, 그 순간 내 마음속에 어떤 생각이 있었는지 적어보세요.
