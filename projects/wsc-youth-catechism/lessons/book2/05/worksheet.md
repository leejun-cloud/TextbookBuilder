# 활동지 — 2권 제 5 과 (소요리문답 제 57 문, 제4계명)

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채우며 소요리문답 57문을 외워보세요.

문) 제4계명은 무엇인가?
답) 제4계명은 "안식일을 (　　　　　　)하여 거룩히 지키라. 엿새 동안은 힘써 네 모든 일을 행할 것이나 (　　　　　)은 네 하나님 여호와의 안식일인즉 너나 네 아들이나 네 딸이나 네 남종이나 네 여종이나 네 가축이나 네 문 안에 있는 객이라도 아무 일도 하지 말라. 이는 엿새 동안에 나 여호와가 (　　　　)과 (　　　)과 (　　　)와 그 가운데 모든 것을 만들고 제칠일에 (　　　　)음이라. 그러므로 나 여호와가 안식일을 (　　　　)하여 그날을 거룩하게 하였느니라" 하신 것이다.

## 2. 순서 맞춰보기 🔢

오늘 배운 논증의 흐름입니다. 맞는 순서대로 번호(1~5)를 적어보세요.

(　　) 안식일은 도덕법이므로 지금 우리에게도 여전히 유효하다.
(　　) 하나님이 창조 때 일곱째 날에 안식하시고, 그날을 복되게 하사 거룩하게 하셨다.
(　　) 진짜 안식은 우리가 쉬는 동안 하나님이 우리 안에서 일하시고, 우리가 그분과 함께 쉬는 것이다.
(　　) 그리스도께서 안식일 후 첫날에 부활하셔서, 안식일이 주일(주의 날)로 성취되었다.
(　　) 제4계명은 창조 때 세워진 안식일의 질서를 다시 한번 확정한 것이다.

## 3. 나의 '주일 성수' 점검표 ✅

지난 4주간의 주일을 떠올리며 체크해보세요.

|  | 그렇다 | 가끔 그렇다 | 아니다 |
|---|---|---|---|
| 주일에 공예배(주일예배)에 참석했다 | ☐ | ☐ | ☐ |
| 주일에 말씀 읽기나 기도에 따로 시간을 냈다 | ☐ | ☐ | ☐ |
| 주일에 밀린 과제·업무·아르바이트를 했다 | ☐ | ☐ | ☐ |
| 주일이 다른 요일과 크게 다르지 않게 지나갔다 | ☐ | ☐ | ☐ |
