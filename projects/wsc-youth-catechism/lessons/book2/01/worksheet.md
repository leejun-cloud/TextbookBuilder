## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러나 이 계명은 법정의 맹세뿐 아니라, 일상에서 하나님의 이름과 관련된 모든 말과 표현까지 다룬다.
( ) 하나님의 이름은 그냥 부르는 호칭이 아니라 하나님 자신과 그 성품, 뜻, 임재를 대표한다.
( ) 그래서 하나님의 이름을 걸고 거짓되거나 무모하게 말하거나, 아무 생각 없이 가볍게 내뱉는 것은 죄가 된다.
( ) 다만 맹세 자체가 잘못된 것은 아니고, 중대한 사안에서 진실하게 하는 맹세는 합당하다.
( ) 그러므로 하나님의 이름을 어떻게 다루는지는 내가 하나님을 실제로 얼마나 진지하게 여기는지를 보여주는 거울이다.
