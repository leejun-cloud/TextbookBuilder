## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 성례의 표징(물, 떡과 잔) 자체에는 은혜를 만들어내는 신비한 능력이 없다.
( ) 그렇다고 성례를 집례하는 사람의 경건함이나, 받는 사람의 정성으로 효력이 생기는 것도 아니다.
( ) 성례가 효력 있는 첫 번째 이유는 그리스도께서 직접 세우시고 그 말씀에 은총의 약속을 담아두셨기 때문이다.
( ) 두 번째 이유는 믿음으로 받는 사람 안에서 성령께서 실제로 역사하시기 때문이다.
( ) 그러므로 성례를 대할 때는 물건이나 절차가 아니라, 그리스도와 성령을 믿음으로 바라보아야 한다.
