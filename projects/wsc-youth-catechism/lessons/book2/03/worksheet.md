## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러므로 하나님과 관련된 것 — 이름, 말씀, 예식, 맹세 — 을 대하는 태도 하나하나가 다 중요하다.
( ) 맹세는 하나님의 이름을 가장 직접적으로 사용하는 대표적인 행위다.
( ) 헛되거나 무모하게 맹세하거나, 하나님이 아닌 다른 것으로 맹세하는 것은 죄다.
( ) 합법적 맹세 자체는 죄가 아니라 예배의 한 부분이다.
( ) 하나님은 이름, 말씀, 성례, 기도, 하신 일들을 통해 자신을 나타내신다.
