# 활동지 — 2권 제 8 과 (소요리문답 제 60 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채우며 오늘의 문답을 완성해보세요.

문) 안식일을 어떻게 거룩하게 지켜야 하는가?
답) 안식일은 (          ) 거룩한 안식을 지킴으로써 거룩하게 지켜야 하니, 다른 날에 하는 (          ) 세상 일과 (          )까지도 쉬고, 그 모든 시간을 (          )으로나 (          )으로 하나님께 드리는 예배와 (          )한 일과 (          )를 베푸는 일을 행하는 데 쓰는 것이다.

## 2. 순서 맞춰보기 🔢
오늘 배운 논증 흐름을 순서대로 번호(1~5)를 매겨보세요.

(  ) 세속적인 일과 오락을 비운 그 자리는 텅 비워두는 것이 아니라, 예배와 의무로 다시 채워진다.
(  ) 안식일은 예배 한 시간만 잘 드리면 되는 날이 아니라, 하루 전체가 그 방향으로 맞춰져야 하는 날이다.
(  ) 평일에는 정당한 일과 오락도, 안식일에는 온종일 쉬어야 한다.
(  ) 그러나 필연적인 일과 자비를 베푸는 일은 예외로 허락된다. 예수님도 안식일에 선을 행하는 것이 옳다고 하셨다.
(  ) 결국 안식일은 사람을 얽매려는 규정이 아니라, 사람을 위해 주어진 쉼과 회복의 날이다.

## 3. 나의 '주일 하루' 점검표 ✅
지난 주일 하루를 떠올리며 해당하는 항목에 체크해보세요.

□ 공적 예배(주일예배)에 참석했다
□ 개인적으로 말씀을 읽거나 기도하는 시간을 가졌다
□ 가족이나 신앙의 사람들과 신앙에 관해 이야기를 나눴다
□ 평소 하던 과제, 아르바이트, 게임 등을 그대로 이어서 했다
□ 주변 사람을 돕거나 자비를 베푸는 행동을 했다

서술형 질문: 위 체크 결과를 보고, 나의 주일은 "예배 + 필연적 의무 + 긍휼의 의무"로 채워진 하루에 가까웠나요, 아니면 평일과 비슷한 하루에 가까웠나요? 한두 문장으로 적어보세요.
