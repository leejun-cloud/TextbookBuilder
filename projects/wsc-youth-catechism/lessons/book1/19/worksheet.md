# 활동지 — 1권 제 19 과 (소요리문답 제 21 문)
## 택하신 자들의 구속주 그리스도

### 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 오늘의 문답을 완성해 보세요.

문) 하나님께서 선택하신 사람들의 구속자는 누구이신가?

답) 하나님께서 선택하신 사람들의 구속자는 오직 주 (            )이시니, 그는 하나님의 (              )으로서 (        )이 되사, 한 (        ) 안에 (        )과 (        ) 두 본성을 지니시고, 지금도 그리고 (              ) 그러하시다.

### 2. 순서 맞춰보기 🔢
오늘 배운 논증의 흐름입니다. 순서에 맞게 번호(1~5)를 매겨 보세요.

(  ) 하나님과 사람 사이를 중재하려면 하나님도 온전히 알고 사람도 온전히 아는 분이어야 하므로, 중보자는 오직 한 분, 예수 그리스도뿐이다.

(  ) 하나님은 창세 전부터 아들 안에서 한 백성을 택하시고, 그들을 구속하기로 영원히 작정하셨다.

(  ) 그 아들이 동정녀 마리아에게서 성령으로 잉태되어 참 사람이 되셨다(성육신).

(  ) 그리스도는 한 위격 안에 신성과 인성 두 본성을 나뉠 수 없이 지니셨기에, 사람으로서 죽으시고 하나님으로서 그 죽음에 무한한 가치를 부여하실 수 있었다.

(  ) 부활·승천하신 지금도 그리스도는 여전히 참 하나님이시자 참 사람으로서, 하나님 우편에서 우리를 위해 영원토록 간구하신다.
