# 활동지 28과 — 성령의 구속 적용

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 성령께서는 그리스도께서 값 주고 사신 구속을 우리에게 어떻게 적용하시는가?
답: 성령께서는 우리 안에 ______________을 일으키시고 그로써 우리를 ______________ 부르심 안에서 그리스도와 ______________하게 하심으로, 그리스도께서 값 주고 사신 구속을 우리에게 적용하신다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그리스도께서 십자가와 부활로 구속을 완전히 이루셨다.
( ) 성령께서 우리 안에 믿음을 일으키신다.
( ) 성령께서 부르심이 헛되이 지나가지 않고 반드시 응답에 이르게 하신다(효력 있는 부르심).
( ) 그 믿음으로 우리는 효력 있는 부르심 안에서 그리스도와 연합한다.
( ) 그리스도와의 연합으로 그분의 의가 전가되어, 구속이 실제로 내 것이 된다.

## 3. 나의 '믿음의 출처' 점검표 ✅

내 신앙생활을 돌아볼 때, 아래 문장 중 최근 나의 생각과 더 가까운 쪽에 표시해보세요.

- [ ] 나는 내가 스스로 결심하고 애써서 믿음을 키워가고 있다고 느낀다.
- [ ] 나는 내 믿음이 성령께서 주신 선물이라고 느낀다.
- [ ] 둘 다 조금씩 섞여 있는 것 같다.
- [ ] 솔직히 잘 모르겠다.

→ 위에서 표시한 것과 관련해, 오늘 배운 "믿음은 성령께서 일으키신 선물"이라는 사실이 내 생각을 어떻게 바꾸어 놓나요?
