## 2. 순서 맞춰보기 🔢
오늘 "말씀 속으로 한 걸음"에서 다룬 논리를 순서대로 번호를 매겨보세요.

(  ) 침묵도 때로는 진실을 해치는 방법이 될 수 있다 — 말해야 할 자리에서 말하지 않는 것도 문제다.
(  ) "진실을 해치는 것"은 거짓말뿐 아니라, 왜곡하거나 절반만 말하는 것까지 포함한다.
(  ) 좋은 의도였다는 것과 실제로 이웃에게 해가 되었다는 것은 별개의 문제다.
(  ) 나 자신에 대해서도 부풀리거나 거짓 겸손으로 낮추지 말고 있는 그대로 말해야 한다.
(  ) 이웃의 허물을 굳이 들추고 퍼뜨리는 것, 사실이 아닌 말로 남을 깎아내리는 것 모두 이 계명이 금하는 것이다.
