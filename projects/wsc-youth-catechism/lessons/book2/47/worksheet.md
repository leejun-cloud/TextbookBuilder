## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 그러므로 우리는 스스로를 근거로 삼지 않고, 오직 하나님을 근거로 삼아 기도한다.
( ) 나라와 권세와 영광은 이미 다 아버지께 속해 있다.
( ) 나라는 다스리심을, 권세는 이루실 능력을, 영광은 그 모든 것의 최종 목적을 뜻한다.
( ) 마지막으로 "아멘"이라 말하는 것은 이 기도가 반드시 이루어진다는 확신의 표현이다.
( ) 그래서 기도는 나를 위한 요청으로 끝나지 않고, 하나님께 영광을 돌리는 것으로 완성된다.
