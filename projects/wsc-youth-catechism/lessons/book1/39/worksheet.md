# 활동지 39과 — 십계명의 총의(강령)

## 1. 오늘의 문답 외워보기 ✍️

빈칸을 채워보세요.

문: 십계명의 강령은 무엇인가?
답: 십계명의 강령은 우리 마음을 다하고 ______________을 다하고 ______________을 다하고 뜻을 다하여 주 우리 하나님을 사랑하고, 또 우리 이웃을 ______________같이 사랑하는 것이다.

## 2. 순서 맞춰보기 🔢

아래 문장들을 오늘 배운 논리 순서대로 번호를 매겨보세요. ( ) 안에 1~5 숫자를 쓰세요.

( ) 십계명은 제1~4계명(하나님 사랑)과 제5~10계명(이웃 사랑), 두 부분으로 나뉜다.
( ) 이 두 부분을 한 마디씩으로 요약하면 "하나님 사랑"과 "이웃 사랑"이 된다.
( ) 열 가지 구체적 조항은 이 두 원리가 삶의 자리마다 어떻게 적용되는지를 보여준다.
( ) 하나님 사랑이 먼저이고 그 바탕 위에서 이웃 사랑이 따라온다.
( ) 그러므로 사랑은 십계명 전체를 완성하는 강령이다.

## 3. 나의 '사랑의 우선순위' 점검표 ✅

지난 한 주를 돌아볼 때, 아래 중 나에게 더 소홀했던 쪽에 표시해보세요.

- [ ] 하나님과의 시간(기도, 말씀, 예배)을 뒤로 미룬 적이 많았다
- [ ] 가까운 사람에게 짜증이나 무관심으로 대한 적이 많았다
- [ ] 규칙은 지켰지만 마음은 억지였던 순간이 많았다
- [ ] 특별히 소홀한 쪽 없이 균형 있게 지냈다
- [ ] 기타: ___________

→ 위에서 표시한 항목이 있다면, 그것이 "하나님 사랑" 쪽인가요 "이웃 사랑" 쪽인가요? 그 이유는 무엇이라고 생각하나요?
