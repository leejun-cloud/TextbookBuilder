# 활동지 — 2권 제 9 과 (소요리문답 제 61 문)

## 1. 오늘의 문답 외워보기 ✍️
빈칸을 채워 소요리문답 61문을 완성해보세요.

문) 제4계명이 금하는 것은 무엇인가?
답) 제4계명이 금하는 것은 명하신 (          )를 이행하지 않거나 소홀히 이행하는 것이며,
(          )으로 그날을 더럽히거나, 그 자체로 (          )가 되는 일을 행하거나,
세상 일과 오락에 관한 불필요한 (          )과 말과 행동으로 그날을 더럽히는 것이다.

## 2. 순서 맞춰보기 🔢
오늘 본문에서 배운 "제4계명이 금하는 네 가지"를 논리적인 순서(원문 순서)대로 번호를 매겨보세요.

(  ) 그 자체로 죄가 되는 일을 행하는 것
(  ) 세상 일과 오락에 관한 불필요한 생각·말·행동으로 그날을 더럽히는 것
(  ) 명하신 의무를 이행하지 않거나 소홀히 이행하는 것
(  ) 게으름으로 그날을 더럽히는 것
